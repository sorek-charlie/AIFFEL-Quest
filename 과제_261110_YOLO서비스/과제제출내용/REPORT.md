# 선택과제 A 제출 보고서
## 버스 사진의 객체 탐지·분할과 임계값 비교

### 수행 목적
사진에서 버스·사람의 위치를 구조화 데이터로 추출하고, 박스와 마스크의 차이를 원본과 대조한다. 입력은 첨부 bus.jpg(810×1080)이며 공개 사전학습 모델로 추론하였다.

### 실행 환경
ChatGPT 작업 환경의 Linux x86_64 / Python 3.12.14 / CPU에서 실행하였다. Ultralytics 8.4.208, torch 2.15.0+cpu, torchvision 0.29.2+cpu, numpy 2.3.5, Pillow 13.0.0을 사용했다. 탐지 yolo26n.pt와 분할 yolo26n-seg.pt를 imgsz=640, conf=0.25 및 0.50으로 각각 실행했다. 상세 해시·입력·버전은 manifest.json에 기록했다.

### 실제 결과
| 작업 | conf=0.25 | conf=0.50 | 변화 |
|---|---|---|---|
| 탐지 | bus 1, person 4 | bus 1, person 4 | 수·클래스 동일 |
| 분할 | bus 1, person 4 | bus 1, person 4 | 수·클래스 동일 |

탐지 결과의 최저 점수는 0.6562로 0.50보다 높다. 분할 결과도 모든 점수가 0.50 이상이어서 이번 비교에서는 제거되는 객체가 없었다. 따라서 임계값을 높이면 반드시 박스가 줄어드는 것은 아니다. 이 결과는 이 사진·모델·설정에 한정된다.

### 좌표 대조
아래는 detect_0.25/boxes.json의 실제 출력이다. 좌표는 원본 픽셀 기준 xyxy이고 소수 첫째 자리로 표시했다. 원시 JSON은 반올림하지 않고 보존했다.

id | 클래스 | 점수 | x1, y1, x2, y2
0 | bus | 0.8806 | 0.0, 230.5, 803.2, 750.7
1 | person | 0.8720 | 48.6, 397.7, 240.3, 902.4
2 | person | 0.8608 | 222.9, 404.8, 345.5, 861.0
3 | person | 0.8462 | 669.6, 394.5, 809.9, 879.4
4 | person | 0.6562 | 0.2, 553.0, 59.7, 871.3

버스 id=0의 박스는 왼쪽 위 (0.0, 230.5), 오른쪽 아래 (803.2, 750.7)이다. 너비는 약 803.2px, 높이는 약 520.2px이다. 버스 전면과 측면을 감싸지만 앞을 가린 사람과 배경도 박스 내부에 들어간다. 객체 탐지 박스만으로 해당 픽셀이 버스라고 단정할 수 없다.

### 원본 대조·오류 및 확인 필요 기록
| 검토 대상·위치 | 실제 관찰과 해석 | 수정·확인 상태 |
|---|---|---|
| 버스 상단, 원본 y≈230~310 | 지붕을 포함한 넓은 박스 및 분할 윤곽을 확인했다. 사각형 안에는 배경도 포함된다. | 원시 출력 수정 없음 |
| 버스 앞의 두 사람, x≈50~345 / y≈400~900 | 두 사람은 별도 person으로 탐지되며 버스와 겹치는 위치에 있다. 분할은 사람을 버스와 구별하는 픽셀 정보를 제공한다. | 가림 경계 정밀 정확도는 정답 마스크 없어 미확인 |
| 왼쪽 가장자리 사람, x≈0~60 / y≈550~875 | 화면 밖으로 잘린 사람도 탐지되었다. 탐지 점수 0.6562로 다른 사람보다 낮았다. 잘렸다는 사실이 점수 차이의 원인이라고 확정할 수는 없다. | 누락된 화면 밖 신체는 추측하지 않음 |
| 오른쪽 사람, x≈670~810 / y≈395~880 | 잘린 사람의 박스와 마스크를 확인했다. 화면 밖까지의 실제 모양은 알 수 없다. | 원시 출력 수정 없음 |
| 도로의 긴 그림자, y≈900~1080 | 비교 화면에서 긴 그림자는 사람 마스크와 대부분 구분된다. 모든 경계 픽셀이 정확하다는 뜻은 아니다. | 픽셀 단위 정확도 미확인 |

분할 PNG는 객체마다 810×1080 크기로 저장하고 다시 열어 크기를 확인했다. mask_XX.png의 흰색은 해당 객체의 예측 영역, 검정은 그 밖의 영역이다. boxes.json의 mask_file로 객체와 마스크를 연결한다. 원시 결과는 수동 수정하지 않았다.

### 예상과 결과 비교
가려지거나 가장자리에서 잘린 사람을 놓칠 가능성을 예상했다. 이번 실행에서는 육안으로 확인되는 주요 보행자 네 명과 버스 한 대가 모두 출력되었다. 단, 배경의 모든 가능한 객체를 전수 확인한 것은 아니며 정답 라벨을 만들지 않아 성능 수치로 일반화하지 않는다.

### 한계 및 결론
박스는 대상의 위치를, 마스크는 예측 픽셀 경계를 제공한다. 두 임계값 모두 같은 객체 수를 보였으며 이는 점수 분포로 설명된다. 정답 데이터가 없으므로 precision·recall·IoU·mAP는 보고하지 않았다. 별도 자기 사진 재실행, 웹 업로드 UI, 공개 배포는 수행하지 않았다. 강의에서는 노트북·코드 기반 실행도 허용하므로 본 제출은 CLI 실행 코드와 저장된 결과로 구성하였다.

### 재실행·제출
README.md에 설치·실행·출력 파일 설명과 평가 기준 대응을 정리하였다. run.py로 다른 사진 경로를 받을 수 있다. 결과 비교 이미지 2장과 원본·좌표·마스크·manifest·실행 코드를 함께 제출한다. 전체 폴더를 GitHub 또는 Google Drive에 올리고 채점자가 접근 가능한 링크를 강의 제출란에 입력한다. 실제 제출 버튼은 누르지 않았다.
