# Google 자료 동기화·누락 보충 검증 계획

**검토용 초안 · 아직 새 기능을 구현·실행 검증하지 않았습니다.**

## 이번에 확인한 사실

Quest_03의 `google-schedule.mjs`와 `sync-manager.mjs`를 읽었습니다. 08·12·18·24시의 다음 실행 시각을 계산하고, 앱 실행 중 주기적으로 확인하는 코드가 있습니다. 시작 시 다음 실행 시각을 계산하므로 앱이 꺼져 놓친 시각을 즉시 보충하는 처리는 추가가 필요합니다. 이 확인은 소스 점검이며 실제 Google 조회 테스트 결과가 아닙니다.

## 검증 순서

1. 가짜 시계·가짜 Google 응답으로 정시·누락·실패·동시 실행을 검사합니다. 이 단계에서는 실제 계정을 사용하지 않습니다.
2. 사용자의 PC 앱에 이미 연결된 계정으로 실제 읽기 조회를 확인합니다. 비밀번호·키·토큰은 기록하지 않습니다.
3. 앱 종료·재실행, 절전 복귀, 연결 복구 후 마지막 성공 시각과 결과를 확인합니다.
4. 스킬을 프로젝트에 설치하고 새 대화에 “놓친 구글 자료 가져와 줘.”만 입력합니다. 실제 선택된 스킬과 실행 결과를 기록합니다.
5. 실행 명령·날짜·결과·한계를 기록한 뒤 최종 제출물을 갱신합니다.
