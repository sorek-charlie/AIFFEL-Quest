Google 자료 동기화·누락 보충 스킬

검토용 초안 · 2026-11-03

반복 작업의 주제를 기존 “과제 제출 점검”에서 Gmail·Google 캘린더 정기 조회와 놓친 조회 보충으로 변경했습니다. 프로그램 구현에 들어가기 전에 확인할 문서입니다.

불편 → 해결

PC 앱을 사용하면서 Gmail·Google 캘린더를 다시 확인하도록 반복해서 요청했습니다. 매일 08·12·18·24시에 조회하더라도 노트북이나 앱이 꺼져 있으면 최신 자료를 놓칠 수 있습니다.

앱이 시작되거나 절전에서 돌아오면 마지막 성공 기록을 확인하고, 놓친 조회가 있을 때 즉시 한 번 현재 자료를 가져오는 방식으로 개선하려 합니다. 스킬은 AI가 이 조회 기능을 실행·점검하는 절차이며, 정시 실행과 누락 감지는 프로그램이 담당합니다.

예정 동작 예시

상황 예정 동작
08:00 앱 실행 중 Gmail·캘린더 정기 조회
08:00 꺼짐 → 09:20 앱 실행 마지막 성공 확인 후 누락 조회 즉시 한 번
08·12·18시 모두 놓침 → 20:10 앱 실행 놓친 횟수만큼 반복하지 않고 현재까지 한 번 보충
12:00 절전 → 13:30 복귀 누락 여부 확인 후 필요할 때 한 번 조회
인터넷 단절 → 다시 연결 마지막 성공 기준으로 누락 조회
Gmail 실패·캘린더 성공 성공 기록을 분리하고 Gmail만 재시도
노트북만 켜지고 앱은 실행 안 됨 동작하지 않음. OS 자동 시작은 별도 설정 필요

시간대는 Asia/Seoul이며 24:00은 다음 날 00:00입니다. 가져온 메일 후보는 검토 후 저장하고 캘린더의 중복·충돌 처리는 유지합니다.
