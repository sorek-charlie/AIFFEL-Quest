## PRD 요약

### 제품 개요
- **목적:** 태양계 공간에서 대규모 외계 함대와 교전하는 빠르고 화려한 3D 우주 전쟁 게임
- **핵심 재미:** 적 탄막을 피하면서 5종 무기를 바꿔 쓰고, 함선 격침과 대규모 폭발을 직접 만들어 내는 것
- **대상:** 짧은 시간에 우주 전쟁의 장관과 즉각적인 조작감을 즐기려는 캐주얼 액션 플레이어
- **형태:** 브라우저 싱글플레이, 3인칭 추적 시점, PC(키보드·마우스) 우선 + 모바일 터치 지원
- **한 판 길이:** 3~5분 목표

### 게임 진행
행성 선택 → 출격 → 1차 방어전 → 증원 함대 격퇴 → 외계 기함 격침 → 결과 확인

| 단계 | 목표 |
|---|---|
| 웨이브 1 | 적 전투기 12기 격추 |
| 웨이브 2 | 증원 함대 18기 격추 |
| 웨이브 3 | 외계 기함(방어력 260)과 호위 편대 격파 |
| 승리 / 패배 | 기함 격침 시 승리 / 플레이어 방어막 소진 시 패배 |

- 방어막 100, 부스트 에너지 100, 미사일 12발로 시작
- 점수: 일반 전투기 200점, 중장갑 공격선 350점, 기함 12,000점 (최고 점수는 브라우저에 저장)
- 동시에 약 25~34기의 적이 활동

### 3D 우주와 함선
- 수성부터 해왕성까지 **8개 행성**을 전장으로 선택 (지구의 바다·대륙, 목성의 띠, 토성의 입체 고리 등)
- 플레이어 전투기 1종, 외계 전투기 4종(요격기·날개형·원형 공격선·중장갑), 최종 보스 **외계 기함**
- 아군 편대와 배경 전함으로 함대전 규모감 연출

### 5종 무기

| 키 | 무기 | 특징 |
|---|---|---|
| 1 | 쌍발 레이저 | 고속 연사, 탄약 무제한 |
| 2 | 플라스마 산탄포 | 5발 부채꼴 발사 |
| 3 | 유도 미사일 | 적 추적 + 주변 폭발 피해 (Q로도 발사) |
| 4 | 레일건 | 일직선 관통 공격 |
| 5 | 광역 EMP | 전장 전체 피해 + 적 탄막 제거, 재사용 대기 9초 |

### 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | `W A S D` / 방향키 | 왼쪽 가상 조이스틱 |
| 조준 | 마우스 | 조이스틱 방향 |
| 발사 | 클릭 / `Space` | FIRE |
| 무기 전환 | `1`~`5` | 무기 버튼 |
| 유도 미사일 | `Q` | 미사일 버튼 |
| 부스트 | `Shift` | BOOST |
| 일시 정지 | `P` | 상단 버튼 |

### 기능·성능 요구사항
- **필수 기능(P0) 11개:** 실제 3D 렌더링(WebGL), 8개 행성 전장, 입체 기체, 대규모 함대, 무기 5종, 정확한 명중 판정, 보스와 승패, 빠른 조작 반응, 화려한 효과, 안정적인 재시작, 모바일 대응
- **개선 기능(P1):** 저사양용 세부 품질 설정
- **성능 목표:** 데스크톱 평균 60 FPS, 모바일 평균 30 FPS, 입력 반응 100ms 이하, 5초 이내 출격 가능

### 구현 현황과 출시 범위
- 2026-10-27 기준 3D 전장, 입체 함선, 8개 행성, 외계 전투기 4종, 기함, 5종 무기, HUD가 구현되어 있고, 주요 전투 동작을 로컬 브라우저에서 확인했습니다.
- 레일건 명중, 보스전 승리 흐름, 모바일 조작, 성능 목표는 추가 검증 대상입니다.
- 멀티플레이, 계정·성장, 상점, 온라인 랭킹, 행성 착륙은 첫 출시 범위에서 제외합니다.
- 출시 판단 기준: **아름다운 우주, 대규모 교전, 5종 무기의 차별성, 빠른 반응, 안정적인 한 판 완주**
