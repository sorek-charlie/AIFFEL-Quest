### 배포 방식
- 저장소 `sorek-charlie/AIFFEL-Quest`의 `main` 브랜치 루트(`/`)를 GitHub Pages로 공개하고 있습니다.
- 게임은 [`Quest2_release/index.html`](./Quest2_release/index.html) **한 파일**에 3D 엔진(three.js)·텍스처·스크립트가 모두 들어 있어, 외부 파일이나 서버 없이 그 주소만으로 실행됩니다.
- PC는 키보드·마우스, 휴대폰은 화면의 가상 조이스틱·FIRE·BOOST·무기 버튼으로 조작합니다.
- **전투 개시 버튼을 누르는 순간부터 배경음악과 효과음이 나옵니다.** 소리는 오른쪽 위 볼륨 슬라이더나 `−` / `+` 키로 줄이거나 키울 수 있고, `M` 키나 SOUND 버튼으로 끌 수 있습니다.

## PRD 요약

### 제품 개요
- **목적:** 태양계 공간에서 대규모 외계 함대와 교전하는 빠르고 화려한 3D 우주 전쟁 게임
- **핵심 재미:** 적 탄막을 피하면서 5종 무기를 바꿔 쓰고, 함선 격침과 대규모 폭발을 직접 만들어 내는 것
- **대상:** 짧은 시간에 우주 전쟁의 장관과 즉각적인 조작감을 즐기려는 캐주얼 액션 플레이어
- **형태:** 브라우저 싱글플레이, 3인칭 추적 시점, PC(키보드·마우스) 우선 + 모바일 터치 지원
- **한 판 길이:** 3~5분 목표

### 게임 진행
행성 선택 → 출격 → 1차 방어전 → 증원 함대 격퇴 → 외계 기함 격침 → 결과 확인

| 단계 | 목표 |
|---|---|
| 웨이브 1 | 적 전투기 12기 격추 |
| 웨이브 2 | 증원 함대 18기 격추 |
| 웨이브 3 | 외계 기함(방어력 260)과 호위 편대 격파 |
| 승리 / 패배 | 기함 격침 시 승리 / 플레이어 방어막 소진 시 패배 |

- 방어막 100, 부스트 에너지 100, 미사일 12발로 시작
- 점수: 일반 전투기 200점, 중장갑 공격선 350점, 기함 12,000점 (최고 점수는 브라우저에 저장)
- 동시에 약 25~34기의 적이 활동

### 3D 우주와 함선
- 수성부터 해왕성까지 **8개 행성**을 전장으로 선택 (지구의 바다·대륙, 목성의 띠, 토성의 입체 고리 등)
- 플레이어 전투기 1종, 외계 전투기 4종(요격기·날개형·원형 공격선·중장갑), 최종 보스 **외계 기함**
- 아군 편대와 배경 전함으로 함대전 규모감 연출

### 5종 무기

| 키 | 무기 | 특징 |
|---|---|---|
| 1 | 쌍발 레이저 | 고속 연사, 탄약 무제한 |
| 2 | 플라스마 산탄포 | 5발 부채꼴 발사 |
| 3 | 유도 미사일 | 적 추적 + 주변 폭발 피해 (Q로도 발사) |
| 4 | 레일건 | 일직선 관통 공격 |
| 5 | 광역 EMP | 전장 전체 피해 + 적 탄막 제거, 재사용 대기 9초 |

### 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | `W A S D` / 방향키 | 왼쪽 가상 조이스틱 |
| 조준 | 마우스 | 조이스틱 방향 |
| 발사 | 클릭 / `Space` | FIRE |
| 무기 전환 | `1`~`5` | 무기 버튼 |
| 유도 미사일 | `Q` | 미사일 버튼 |
| 부스트 | `Shift` | BOOST |
| 일시 정지 | `P` | 상단 버튼 |
| 볼륨 조절 | `−` / `+` 키, 상단 슬라이더 | 상단 슬라이더 |
| 음소거 | `M`, 상단 SOUND 버튼 | 상단 SOUND 버튼 |

### 사운드 시스템 (v1.1 추가)
- **게임 시작과 함께 재생:** 전투 개시를 누르면 엔진 점화음과 출격 팡파르가 울리고 132BPM 전투 배경음악이 시작됩니다. 웨이브 2와 기함전에서 음악이 더 격렬해집니다.
- **이벤트별 효과음:**

| 이벤트 | 소리 연출 |
|---|---|
| 쌍발 레이저 / 플라스마 산탄포 | 좌우로 갈라지는 고음 레이저 / 묵직한 저음 펄스 |
| 유도 미사일 / 레일건 | 상승하는 분사음 / 날카로운 파열음과 금속성 잔향 |
| 광역 EMP | 깊게 떨어지는 초저음과 전장을 쓸고 가는 노이즈 |
| 적 피격 / 격추 | 금속 타격음 / 저음 충격이 실린 폭발 (대형 적은 더 크게) |
| 플레이어 피해 | 충돌음, 방어막 30% 미만이면 경고음 |
| 부스트 | 누르는 동안 이어지는 엔진 가속음 |
| 웨이브 전환 / 기함 출현 | 상승 아르페지오 / 경보 사이렌과 깊은 경적 |
| 기함 격침 / 승리 / 패배 | 7연쇄 대폭발 / 장조 팡파르 / 하강 단조 화음 |

- **볼륨 조절:** 슬라이더와 `−` / `+` 키로 0~100%, `M`으로 음소거. 설정은 브라우저에 저장되어 다음 접속에도 유지됩니다.
- 음원 파일 없이 Web Audio로 실시간 합성해 단일 HTML 파일에서도 그대로 동작하며, 폭발이 겹쳐도 소리가 찢어지지 않도록 컴프레서를 거칩니다.

### 기능·성능 요구사항
- **필수 기능(P0) 12개:** 실제 3D 렌더링(WebGL), 8개 행성 전장, 입체 기체, 대규모 함대, 무기 5종, 정확한 명중 판정, 보스와 승패, 빠른 조작 반응, 화려한 효과와 이벤트별 효과음, 안정적인 재시작, 모바일 대응, 시작 사운드와 볼륨 조절
- **개선 기능(P1):** 저사양용 세부 품질 설정
- **성능 목표:** 데스크톱 평균 60 FPS, 모바일 평균 30 FPS, 입력 반응 100ms 이하, 5초 이내 출격 가능
