# 제출용 가상 샘플

모든 수치·문구는 시연을 위해 독립적으로 만들었다. 실제 회사자료를 익명화한 파일이 아니다. 이름·주민번호·계좌·인증서·연락처가 없으며 `0000000000`은 유효 사업자번호가 아닌 의도적인 가상 식별값이다.

| 파일 | 입력 위치 | 기대 동작 |
|---|---|---|
| [5개년 요약 XLSX](../outputs/main-quest/synthetic-tax-summary.xlsx) | ‘파일 하나씩 입력’ → 회사 내부 → 법인세 종합정보(요약), 연도 자동 | 2021~2025년 과세표준·산출세액·총부담세액 반영 |
| [기타 첨부 TXT](synthetic-note.txt) | 기타 이름 ‘가상 증빙 설명’ / 부서 ‘가상 회계팀’ / 연도2025 입력 후 첨부 | 참고자료로 기록, 자동계산 미반영, 보고서4에 파일명·분류 표시 |

샘플의 과세표준은 8천만·1억·1억2천만·1억4천만·1억6천만원, 산출·부담세액은 720만·900만·1,080만·1,260만·1,440만원이며 공제 입력은 모두 0이다. 금액은 파서 동작 확인용 임의 입력이다. 현행·과거 세율의 정답 예제가 아니다.

근로자·급여·보험료·기신고 공제 세부 증빙을 의도적으로 생략했다. 이 두 파일로 모든 세무 분석이 가능하다고 주장하지 않는다. 현재 화면에 0원이 보이더라도 자료 충분성이나 실제 환급 불가를 확정하지 않는다.

재생성 소스는 `dev/scripts/build_submission_sample.mjs`다. 작성 환경의 `@oai/artifact-tool`이 설치된 node_modules 경로를 `ARTIFACT_NODE_MODULES` 환경변수로 지정한 뒤 Node로 실행한다. 일반 앱 사용·심사에는 재생성이 필요 없다. 샘플은 직접 선택해서 올려야 하며 앱에 자동 주입되지 않는다.
