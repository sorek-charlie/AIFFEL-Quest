# AI 영상 제작 지시서 · 메인퀘스트 3분 시연

작성일: 2026-11-04. 로그인·회원가입·가입 안내·10초 후 자동 로그인 요청까지 반영한 최신 영상 계획이다. 이 파일은 제작 지시서이며 완성 MP4나 실제 촬영 기록이 아니다.

영상 구성 참고: [10컷 사용씬 스토리보드 이미지](docs/submission/storyboard/usage-storyboard-10-scenes.png). AI가 그린 설명용 일러스트이며 실제 앱 캡처와 구분해서 사용한다.

바로 편집에 넣을 파일: [씬별1920×1080 PNG 10장·표시 시간 안내](docs/submission/storyboard/scenes-16x9/README.md). 파일명01~10 순서로 배치하면 총2분50초 구성이 된다.

## 어떤 AI를 사용할까

추천 조합은 **ChatGPT 또는 Claude로 편집 지시서를 다듬고, CapCut에서 실제 화면 녹화에 AI 내레이션과 자막을 붙이는 방식**이다. Canva로 실제 녹화·캡처를 영상 타임라인에 배치하는 방법도 가능하다. 대화형 AI가 MP4를 바로 만드는 기능을 지원하는지는 사용하는 도구에서 확인한다.

앱 화면은 실제 배포 사이트에서 녹화한다. 영상 생성 AI로 새 UI·가짜 클릭·금액을 그려 넣지 않는다. 한국어 음성·요금제·내보내기 조건은 해당 편집 도구에서 확인한다. 강좌가 본인의 실시간 설명을 필수로 요구한다면 AI 음성 제출이 허용되는지 먼저 확인한다.

## 전달할 파일과 촬영 준비

1. 이 파일, `제출보고서.md`, `PRD.md`, `docs/submission/VERIFICATION.md`를 전달한다.
2. https://tax-return-review-quest.pages.dev/ 에서 실제 화면을 녹화한다. 실제 회사자료 대신 `outputs/main-quest/synthetic-tax-summary.xlsx`와 `samples/synthetic-note.txt`만 쓴다.
3. 영상용 가상 ID를 직접 가입한다. 이미 쓰는 실제 비밀번호를 사용하지 말고 입력 장면에서 비밀번호는 화면·자막·음성에 표시하지 않는다.
4. 로그인 화면에서 가입 팝업이 자동으로 뜨는 2~3분을 원본 영상에 기록한다. 최종 영상은 대기 구간만 자르고 ‘방문 2~3분 후 · 대기 구간 편집’이라고 표시한다.
5. 가입 완료 후 10초 카운트다운과 앱 진입은 실제 장면을 사용한다. 카운트다운 구간은 10초를 유지한다. 기존 계정 로그인 장면은 가입 후 로그아웃하고 다시 촬영한다.
6. 주소·기관·파일 선택 창의 개인 경로, 알림, 실제 계정정보가 노출되지 않는지 확인한다. 실제 테스트 중 없는 장면은 추가 촬영하고 존재하지 않는 동작을 만들지 않는다.

## 2분50초 구성표와 내레이션

| 시간 | 실제 화면·편집 | 읽을 말 |
|---|---|---|
| 0:00–0:15 | 서비스 제목, 실제 배포 URL, 로그인 화면 | “경정청구 자료 검토 도우미입니다. 회사의 여러 해 자료를 기관·서류·연도별로 정리하고 검토 결과를 보고서로 확인하는 서비스입니다.” |
| 0:15–0:30 | 로그인 화면의 ID/PW와 회원가입 버튼 | “ID와 비밀번호로 들어갈 수 있고, 처음 방문하면 회원가입을 진행합니다. 회사 첨부자료는 브라우저에서 처리하고 계정 정보와 분리했습니다.” |
| 0:30–0:40 | 실제 자동 팝업, 대기 구간 편집 표시 | “로그인 화면에 2~3분 머물면 가입 안내가 뜹니다. 지금 보시는 장면은 기다리는 구간만 편집했습니다.” |
| 0:40–1:00 | 가입 제출, 실제10초 카운트다운, 앱 진입 | “가입을 완료하면 10초를 기다린 뒤 새 계정으로 자동 로그인합니다. ID와 비밀번호를 다시 입력하는 로그인도 가능합니다.” |
| 1:00–1:25 | 파일 하나씩 입력 → 요약 XLSX 첨부 | “서류별 입력 창에는 기관과 귀속연도별 기본18칸이 있습니다. 지금은 실제 회사와 무관하게 만든 5개년 가상 요약자료를 첨부합니다.” |
| 1:25–1:40 | 기타 이름·부서·연도 입력, TXT 첨부 | “기타 서류는 이름과 부서, 연도를 직접 적습니다. 자동 인식하지 않는 자료는 참고용으로 기록해 계산 반영과 구분합니다.” |
| 1:40–2:00 | 법인 Q&A·검토 현황 | “파일이 있다는 것과 공제 요건을 충족했다는 것은 다릅니다. 법인 질문과 검토 화면에서 추가로 확인할 증빙을 살펴봅니다.” |
| 2:00–2:20 | 5개년 결과와 소계·연노랑 표시 | “결과는 확보 자료 기준의 잠정 검토값입니다. 이 샘플에는 고용·보험료 증빙이 없으므로 0원을 실제 환급 불가 판정으로 해석하지 않습니다.” |
| 2:20–2:40 | 보고서4 두 파일·처리 상태, HTML 저장 | “현재 자료로 보고서를 생성합니다. 업로드 자료분석에서는 파일명과 기관, 귀속연도, 처리 상태를 확인하고 HTML로 저장할 수 있습니다.” |
| 2:40–2:50 | Reset·로그아웃, 다음 개선 한 줄 | “입력은 Reset으로 지우고 로그아웃으로 계정 접속을 종료합니다. 다음에는 전문가 기준 사례로 세액 계산을 검증하겠습니다.” |

최대3분까지 10초 여유를 둔다. 촬영할 때 동작 시간이 길면 중복 클릭·파일 선택 대기를 자르되 동작 결과를 조작하지 않는다.

## AI에게 그대로 복사할 지시문

```text
첨부한 제출보고서·PRD·검증 기록과 실제 앱 녹화를 바탕으로
메인퀘스트 제출용 영상을 편집해 줘.

출력 목표: MP4, 가로16:9, 1920×1080, 한국어 내레이션·자막,
목표2분50초, 최대3분. AI 내레이션 사용이라고 설명란에 표시해 줘.

위 구성표 순서를 따른다.
로그인 → 회원가입 버튼 → 실제 2~3분 후 가입 안내 팝업 →
가입 완료와 실제10초 카운트다운 → 자동 로그인 →
기관·서류·연도별 가상 XLSX 첨부 → 기타 TXT → Q&A·검토 →
5개년 잠정 결과 → 보고서4 HTML 저장 → Reset·로그아웃.

팝업 대기 부분을 자르면 ‘방문2~3분 후 / 대기 구간 편집’ 자막을 넣어 줘.
비밀번호와 파일 선택 창의 개인정보는 보이지 않게 해 줘.
실제 화면의 글자·숫자는 유지해 줘.
확정 환급액·모든 자료 충분·기관 자동수집 완료라고 말하지 마.
0원을 실제 환급 불가의 정답으로 설명하지 마.
없는 장면·버튼·계정·작동 결과를 생성하지 마.
검증 기록에서 미완료인 기능은 완료했다고 표현하지 마.

먼저 장면별 타임코드, 사용할 녹화 구간, 내레이션, 짧은 자막,
추가 촬영 목록을 작성해 줘. 이후 편집 가능한 도구라면 영상으로
내보내고 길이·음량·자막 잘림을 확인해 줘.
MP4 직접 생성이 불가능하면 그 사실과 CapCut용 편집 절차를 제공해 줘.
```

## CapCut 편집과 제출 확인

새 프로젝트에 녹화를 넣고 위 순서로 자른다. 각 장면에 내레이션 텍스트를 넣고 Text-to-Speech에서 한국어 음성을 선택해 생성한다. 자막은 앱 버튼을 가리지 않게 배치하고 화면의 실제 글자가 읽힐 정도만 확대한다. 음악은 없거나 내레이션보다 작게 설정한다. MP4로 내보낸 뒤 처음부터 끝까지 재생한다.

- [ ] 3분 이하, 소리·글자·카운트다운 확인.
- [ ] 실제 회사정보·비밀번호·개인 경로 없음.
- [ ] 편집한 대기 구간과 AI 음성 사용 표시.
- [ ] 실제 배포 주소와 가상 샘플로 촬영.
- [ ] 영상이 실시간 설명 조건에 맞는지 확인.
- [ ] 강좌가 요구하는 제출 위치에 업로드하고 실제 영상 URL 기록.

참고: [CapCut TTS 공식 안내](https://www.capcut.com/help/text-to-speech-feature), [Canva AI 영상 안내](https://www.canva.com/help/create-videos-canva-ai/).
