## 1. 서비스 개요

회사 회계 담당자와 세무사가 여러 해의 경정청구 자료를 기관·서류·연도별로 정리하고, 검토 상태와 추가 확인사항을 보고서로 확인하는 웹 서비스다. 자료가 여러 파일로 흩어졌을 때 누락·귀속연도·입력 근거를 추적하기 어려운 문제를 줄이는 것이 목표다.

## 2. 사용자 흐름과 기능

| 단계 | 제공하는 기능 | 범위 |
|---|---|---|
| 계정 진입 | ID/PW 로그인, 회원가입, 로그아웃 | Cloudflare 서버 인증. 계정 정보와 세션만 저장 |
| 가입 안내 | 로그인 화면 방문 후 120~180초 사이 가입 팝업 | 미가입 방문자에게 안내, 자동으로 계정을 만들지 않음 |
| 가입 완료 | 10초 카운트다운 후 새 계정으로 자동 로그인 | 서버도 가입 후 10초가 지나야 로그인 허용 |
| 자료 입력 | ZIP·XLSX·문자형 PDF, 기관·서류·연도별 개별 입력 | 기본18칸. 기타는 이름·부서·연도를 직접 입력하고 첨부 |
| 검토 | 법인 Q&A, 검토 상태, 부족자료·확인사항 | 파일 첨부와 요건 충족을 구분 |
| 결과 | 연도별·카테고리별·항목별 잠정 결과 | 12월 결산 2021~2025년, 인식 가능한 서식 |
| 보고서 | 1. 연도별·카테고리 요약 2. 요약+항목별 3. 2차 분석·설명 4. 업로드 자료분석 | 현재 세션 자료로 생성, HTML 저장·인쇄 |
| 초기화 | Reset, 새로고침 시 자료 초기화 | 로그인 세션은 별도 쿠키로 유지, 로그아웃으로 종료 |

로그인 기능을 포함한 Cloudflare 배포를 완료했다. 실제 제출용 HTTPS 주소에서 회원가입·실제10초 후 자동 로그인·재로그인·로그아웃·5개년 업로드·보고서1~4 HTML 저장을 검증했다. 가입 안내의2~3분 조건은 브라우저 가상 시계로 확인했다. 자세한 결과는 [검증 기록](docs/submission/VERIFICATION.md)을 참고한다.

## 3. 구현과 데이터 처리

프런트엔드는 HTML·CSS·JavaScript다. 브라우저에서 선택한 원자료를 분석하고 결과를 생성한다. Cloudflare Pages가 웹을 제공하고 Pages Functions와 D1이 회원 인증을 처리한다. 비밀번호는 솔트와 PBKDF2 해시로 저장하고 세션은 Secure·HttpOnly 쿠키를 사용한다. 브라우저 저장소에 비밀번호를 기록하지 않는다. 가입 후 자동 로그인에 필요한 값은 해당 화면 메모리에서만 잠시 사용한다.

계정 DB는 회사 신고서·근로자 자료·생성 보고서를 저장하지 않는다. 실제 회사자료는 저장소 외부에 분리했고, 공개 소스·이력 점검 도구를 사용한다. Windows EXE의 기관 수집 연결은 웹 로그인·업로드와 별개이며 웹에서 공동인증서 수집이 완료됐다고 주장하지 않는다.

## 4. 가상 샘플과 검증

실제 고객자료에서 가져오지 않은 5개년 요약 XLSX와 기타 설명 TXT를 제공한다. 사업자 식별값은 유효 번호가 아닌 `0000000000`이며 이름·주민번호·계좌는 없다. 근로자·보험료 증빙은 의도적으로 생략했다.

샘플은 자료 입력·메타데이터·보고서 흐름을 시연한다. 샘플에서 표시되는 0원은 실제 환급 불가 판정이 아니다. 로그인·가입 타이머는 `dev/tests/auth_qa.py`, 기존 흐름은 `dev/tests/submission_demo_qa.py` 등으로 확인하며 실제 검증 결과와 미완료 범위를 기록한다.

## 5. AI 협업·배운 점·한계

사용자는 세무사 업무로 범위를 정하고, 자료 입력 방식과 표·보고서 표현, 개인정보 공개 제외 기준을 구체화했다. AI는 UI·계산 흐름·파일 파서·테스트·배포·제출 문서 초안을 지원했다. 전문가 결과와 앱 결과의 차이는 계산 검증의 중요성을 드러냈다. UI와 테스트 완료를 세무적 정확성으로 확대 해석하지 않는다.

공제 조합 최적화, 기신고 공제 대체, 농특세·이월·추징의 전체 정합성은 전문가 기준 사례로 추가 검증해야 한다. 노무사 업무·고용지원금 신청·국세청 자동 청구·스캔 PDF OCR은 이번 범위에 포함하지 않는다. 계정의 비밀번호 재설정·이메일 인증·관리자 기능도 이번 구현 범위 밖이다.
