## 실제 녹화와 구분

사용자가 실제 앱 녹화본이 없다고 확인했다. 이 영상은 **실제 앱 캡처+AI 발표자+설명 일러스트**를 합성한 소개 편집본이며 실제 클릭·대기 전체를 촬영한 영상이 아니다. 미촬영 장면은 ‘AI 기능 설명·실제 동작 미촬영’으로 표시하고 음성에서도 구분했다. 실제 대기 구간을 촬영한 것처럼 ‘대기 구간 편집’이라고 표시하지 않았다.

원래 시연 조건을 완전히 충족하려면 [추가 촬영 목록·편집표](../../../docs/submission/storyboard/DREAMINA_실사영상_편집표.md)에 따라 가입 안내2~3분, 가입10초 카운트다운, 파일 선택·업로드, Q&A, HTML 저장과 Reset·로그아웃을 실제 녹화로 교체해야 한다.

Dreamina의1080p 모델은 구독 화면이 나와 결제하지 않았다. 기존 크레딧25로 Seedance1.0Fast의720p 발표자 클립을 만들었다. 원본은1248×704이며 최종1920×1080 영상 안에서 비율을 유지해 확대했다. 발표자 원본이 네이티브1080p인 것은 아니다. 기존 Dreamina AI 워터마크를 유지했다.

한국어 음성은 Microsoft Edge TTS의 `ko-KR-InJoonNeural`로 생성하고 음량을 정규화했다. 자막은 별도 편집에서 합성해 앱 화면의 글자·숫자를 재생성하지 않았다. 소리와 입 모양을 맞춘 토킹 아바타 영상은 아니며 첫5초 발표자 장면 뒤에는 음성 설명과 캡처·일러스트가 이어진다.
