01 서비스 소개
경정청구 자료 검토 도우미입니다. 여러 해의 자료를 기관과 서류, 연도별로 정리하고 검토 결과를 보고서로 확인합니다. 실제 앱 캡처와 AI 발표자로 소개합니다.

02 ID/PW 로그인·회원가입
ID와 비밀번호로 로그인하고 처음 방문하면 회원가입을 진행합니다. 계정 인증정보와 회사 첨부자료를 분리해 처리합니다.

03 방문2~3분 후 가입 안내
가입 안내는 방문 후 이삼 분 사이에 표시됩니다. 지금은 기능 설명이며 실제 대기 녹화는 추가로 필요합니다.

04 가입10초 후 자동 로그인
회원가입 완료 뒤 십 초가 지나면 새 계정으로 자동 로그인합니다. 서버도 십 초 이전 로그인을 막도록 검증했습니다. 이 장면은 기능 설명이며 실제 카운트다운 녹화는 아직 없습니다.

05 기관·서류·연도별 첨부
기관과 서류, 귀속연도별 기본 열여덟 칸에 파일을 하나씩 넣습니다. 시연 자료는 실제 회사와 무관하게 만든 가상 오개년 요약자료입니다. 파일 첨부와 요건 충족은 구분합니다.

06 기타 서류 등록
기타 서류는 이름과 부서, 연도를 직접 입력합니다. 참고용 첨부는 자동계산에 반영되지 않는다고 표시합니다.

07 법인 Q&A·검토
법인 질문과 항목별 검토에서 추가 증빙과 확인사항을 살펴봅니다. 자료가 첨부됐다고 모든 공제 요건이 충족되는 것은 아닙니다. 실제 검토 화면 촬영은 추가로 필요합니다.

08 5개년 잠정 결과
결과는 확보한 자료 기준의 잠정 검토값입니다. 가상 샘플에는 고용과 보험료 증빙이 없습니다. 화면의 영 원을 실제 환급 불가 판정으로 해석하지 않습니다. 세액 계산은 전문가 확인이 필요합니다.

09 보고서4·HTML 저장
현재 업로드 자료로 보고서를 생성합니다. 원자료 보고서에서 파일명과 기관, 귀속연도, 처리 상태를 확인하고 HTML로 저장할 수 있습니다.

10 Reset·로그아웃
Reset은 입력자료를 지우고 로그아웃은 계정 접속을 종료합니다. 다음에는 전문가 기준 사례로 계산을 검증하겠습니다.
