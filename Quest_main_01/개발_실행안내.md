# 경정청구 검토 프로그램

세무사 관련 세액공제·감면과 법인세 경정청구를 검토하는 로컬 프로그램입니다. 회사자료는 포함하지 않습니다. 실행 시 입력은 비어 있으며 사용자가 선택한 ZIP·XLSX·문자형 PDF를 해당 기기에서 처리합니다.

## 제출 주소

- GitHub 저장소: https://github.com/sorek-charlie/AIFFEL-Quest/tree/main/Quest_main_01
- 웹 실행: https://tax-return-review-quest.pages.dev/
- [제출보고서](제출보고서.md) · [PRD](PRD.md) · [회고](retrospective.md) · [AI 협업 기록](docs/submission/AI_COLLABORATION.md)

## 실행

- 브라우저: 루트의 `index.html`을 엽니다.
- Windows: `python dev/scripts/build_exe.py`로 빌드한 `경정청구.exe`를 실행합니다. 제출 폴더의 실행파일을 직접 사용할 수 있습니다.
- 개발 서버: `python -m http.server 8765 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8765/`를 엽니다.

## Cloudflare 배포 업데이트

1. `python dev/scripts/build_web_deploy.py`를 실행합니다.
2. 출력된 `dev/build/web-...` 폴더를 `npx wrangler pages deploy 폴더경로 --project-name tax-return-review-quest --branch main --commit-dirty=true`로 배포합니다.
3. 프로그램 실행 URL과 `/demo/`에서 로그인 화면·데모 재생을 확인합니다.

현재 프로젝트는 Cloudflare Pages Direct Upload와 D1 인증을 사용합니다. `wrangler.jsonc`의 D1 바인딩은 기존 계정 설정에 맞게 관리합니다. 정적 파일만 GitHub Pages에 올리면 서버 인증 API가 제공되지 않습니다.

## 사용 흐름

웹 배포에서는 먼저 ID/PW로 로그인합니다. 로그인 화면의 **회원가입**으로 계정을 만들 수 있고, 미로그인 방문 후120~180초 사이에 가입 안내가 자동으로 열립니다. 가입 완료10초 후 새 ID로 자동 로그인하며, 직접 ID/PW로 다시 로그인할 수도 있습니다. 로그인은 최대8시간 유지되고 상단 **로그아웃**으로 종료합니다. 계정 인증정보는 Cloudflare D1에 저장하며 비밀번호 원문·회사 첨부자료는 저장하지 않습니다. 로그인은 HTTPS 배포용이며 기존 로컬 HTML·EXE는 오프라인 자료 처리 방식입니다.

1. 파일 업로드 또는 법인 공동인증서로 기관자료 수집
2. 법인 Q&A 답변
3. 시뮬레이션 결과·항목별 근거 검토
4. 현재 업로드 자료로 보고서 1~4 생성, HTML 저장 또는 인쇄·PDF 저장
5. 세무사 확인·자료 보완

`파일 하나씩 입력`을 누르면 기관·서류명·귀속연도별 첨부 창이 열립니다. 법인세 신고서 5개년, 보험요율 7개년과 다년도 엑셀 등 기본 18칸에 파일을 하나씩 넣을 수 있습니다. 기타 서류는 파일명·부서·귀속연도를 직접 입력하고 PDF·XLSX·이미지·한글·워드·텍스트 등을 첨부합니다. 자동 인식하지 않는 자료는 참고용으로만 기록합니다. 지정 연도와 법인세 신고서의 귀속연도가 다르면 반영하지 않습니다.

공동인증서 암호는 공식기관 인증화면에서 입력합니다. EXE 수집 창은 WebView2 Runtime을 사용하며 기관별 권한·보안 프로그램이 필요할 수 있습니다. 실제 파일 다운로드 완료 전에는 자료 확보로 표시하지 않습니다.

## 계산 범위

현재 자동계산은 12월 결산 2021~2025년과 인식 가능한 서식에 한정합니다. 공제 조합 최적화와 공제 종류 변경에 따른 세금 조정은 완전하지 않으므로 신고·청구에 바로 사용할 확정 금액이 아닙니다. 실제 증빙과 해당 연도 법령으로 세무사가 확인해야 합니다.

고용지원금 신청·노무사 상담 기능은 포함하지 않습니다. 고용세액공제에 필요한 근로자·급여·사업주 보험료 자료는 입력 대상입니다.

## 공개 저장소와 개인정보

- 실제 회사 원본, 개인정보, 보고서, 화면 캡처, 인증서와 비밀번호를 커밋하지 마세요.
- `input/`, `private/`, `local-data/`, `exports/`, `backups/`, `dev/build/`와 원자료·인증서 확장자는 Git에서 제외합니다. 개인자료는 저장소 밖에 보관하세요.
- `.gitignore`는 이미 커밋된 파일을 지우지 않습니다. 공개 전 `python dev/scripts/check_public_repo.py --history`를 실행하세요.
- 회사별 기본 데이터, 숨겨진 복원 데이터, 회사별 보고서 또는 식별번호는 배포하지 않습니다. 기관 경로와 공개 법령 참고정보만 포함합니다.
- 업로드 자료는 세션에서 처리합니다. Q&A·진행정보 저장이나 내보내기를 사용하면 브라우저 또는 저장 파일에 회사정보가 남을 수 있으니 직접 관리하세요. Reset은 현재 프로그램의 브라우저 상태를 초기화합니다.

## 메인퀘스트 제출 자료

[README](README.md)에 필수 제출 문서 링크를 모았습니다. [가상 샘플 안내](samples/README.md)를 따라 파일을 직접 첨부해 시연할 수 있습니다. 공개 샘플 XLSX 한 파일은 정확한 경로와 SHA-256을 지정해 예외로 허용하며, 실제 회사자료 제외 규칙은 유지합니다.

전체 개요는 [제출보고서.md](제출보고서.md), 영상 구성은 [최종 영상 안내](outputs/main-quest/video/README.md)를 참고하세요.

## 개발·검증 명령

```text
node --test dev/tests/*.test.cjs

python dev/scripts/check_public_repo.py --history
python dev/scripts/build_public_data.py
python dev/scripts/update_manifest.py
python dev/scripts/build_exe.py
python dev/scripts/update_manifest.py
python dev/tests/acquisition-host.test.py
```

테스트 데이터는 실제 회사에서 추출하지 않은 가상 데이터입니다. 테스트 통과는 세법 적합성이나 환급 확정을 보증하지 않습니다.

| 경로 | 내용 |
|---|---|
| `app/assets/` | 입력·계산·분석·수집·보고서 UI |
| `app/data/` | 회사정보 없는 공개 기관 경로·법령 참고정보 |
| `app/vendor/` | 오프라인 라이브러리·WebView2와 라이선스 |
| `docs/` | 일반 사용·자료 확보·출처 안내 |
| `dev/scripts/` | 공개 배포 빌드·점검 도구 |
| `dev/tests/` | 가상 데이터 기반 회귀 테스트 |

GitHub에는 소스와 라이선스를 올립니다. 실제 회사 원자료·생성 보고서·백업은 포함하지 않습니다. 제출용 Windows EXE는 포함합니다. 외부 라이브러리를 재배포할 때 `app/vendor/`의 라이선스도 유지하세요.
