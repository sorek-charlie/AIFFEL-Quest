인증서 형식·로그인 범위

PFX·P12는 암호와 개인키를 로컬 확인합니다. NPKI signCert.der는 공개정보·유효기간만 확인하며, signPri.key·비밀번호는 해당 기관의 보안 인증창에서 입력합니다. 기관마다 인증서 등록·법인 권한·사업장 관리번호가 필요할 수 있습니다.

현재 기관 자동 로그인·발급 메뉴 자동 조작은 미연동입니다. 아래 공식창에서 인증과 조회·발급을 진행하세요. 인증서 로컬 확인 결과로 사업자 일치나 발급 성공을 표시하지 않습니다.

기관·서류·다운로드 메뉴

세액공제 검토에 필요한 기관별 서류를 안내합니다. 세액공제에 필요한 실납부 자료를 수집합니다. 현재 발급 경로와 2021~2025년 적용 법령은 별도로 관리합니다.

서류 / 발급기관인증 이후 다운로드 메뉴파일·부족자료기관 연결

수집할 서류에서 ‘이 자료 수집 선택’을 누르세요. 귀속연도는 원문에서 확인합니다.

자동 수집 이력 없음
폴더에 저장된 파일만 읽습니다. 브라우저의 기본 다운로드 폴더는 바꾸지 않습니다. 인쇄 전용 문서는 PDF 저장이 가능한 경우 저장하고, 기관 보안뷰어에서 제한되면 기관 제공 방식을 이용하세요. 참고 PDF 접수는 공제요건 확인 완료를 뜻하지 않습니다.

정책·메뉴 변경 반영

새 수집경로 JSON의 공식 주소·확인일·변경 메뉴를 미리 보고 적용합니다. EXE 재설치 없이 경로를 바꿀 수 있습니다. 자동 정책감지·자동 갱신 서버는 아직 연결되지 않았으며, 공식 공지 확인 후 검증된 경로 파일을 반영해야 합니다.

기관 화면 경로 갱신으로 과거연도 공제율·기한·수급요건을 자동 덮어쓰지 않습니다. 기관 사이트에 접속했거나 파일이 생겼다는 이유로 인증·자료확보 완료를 표시하지 않습니다.
