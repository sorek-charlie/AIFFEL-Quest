# 경정청구 자료 검토 도우미

회사 회계 담당자와 세무사가 여러 해의 경정청구 자료를 기관·서류·연도별로 정리하고, 추가 확인사항과 잠정 검토 결과를 보고서로 확인하는 웹 서비스입니다.

## 1. [▶ 데모 영상 바로 재생 — 2분50초](https://tax-return-review-quest.pages.dev/demo/)

링크를 열고 **‘데모 재생’** 버튼을 누르면 웹브라우저 안에서 영상이 재생됩니다. GitHub의 MP4 파일 미리보기나 Windows 기본 동영상 앱을 거치지 않습니다. 재생·일시정지·구간 이동·전체 화면을 사용할 수 있습니다.

1920×1080 영상에 한국어 남성 AI 내레이션과 자막이 포함돼 있습니다. 실제 앱 캡처와 실사형 AI 발표자를 사용한 소개 편집본이며, 실제 클릭·대기 전체를 촬영한 영상은 아닙니다. 미촬영 장면은 영상 안에서 기능 설명으로 구분했습니다.

## 2. [▶ 프로그램 실행 URL](https://tax-return-review-quest.pages.dev/)

회원가입 또는 ID/PW 로그인으로 시작합니다. 회원가입을 완료하면10초 후 새 계정으로 자동 로그인합니다. 로그인 화면에2~3분 머무르면 가입 안내가 표시됩니다.

자료 업로드 → 법인 Q&A → 시뮬레이션 결과 → 항목별 검토 → 보고서 저장 순서로 사용합니다. 기본18칸에서 기관·서류·귀속연도별로 파일을 넣고, 기타 서류는 이름·부서·연도를 직접 적어 첨부할 수 있습니다. 선택한 회사 원자료는 브라우저에서 처리하며 표시 금액은 전문가 확인이 필요한 잠정값입니다.

## 3. [GitHub 레포지터리·제출 폴더](https://github.com/sorek-charlie/AIFFEL-Quest/tree/main/Quest_main_01)

최종 프로그램 소스, Windows 실행파일, 제출 문서, 가상 샘플, 씬 이미지와 데모 영상이 들어 있습니다. 기존 Quest_01~04와 구분되는 Quest_main_01 폴더로 제출했습니다. 프로그램 사용은 위2번 실행 URL, 영상 감상은1번 웹 재생 링크를 이용하세요.

## 4. [PRD — 서비스 기획·요구사항·검증 기준](PRD.md)

서비스가 해결하려는 문제와 대상 사용자, 핵심 사용 흐름, 최소 성공 기준을 정리했습니다. 회원 진입·자료 정리·결과 검토·보고서 생성의 구현 범위와 이번에 만들지 않는 기능을 구분합니다. 확인한 동작과 추가 검증이 필요한 세액 계산의 한계도 명시했습니다.

## 5. [회고록 — 배운 점·어려움·다음 단계](retrospective.md)

자료 입력 방식을 구체화한 과정, 전문가 결과와 앱 결과의 차이에서 배운 점, 실제 회사자료와 공개 소스를 분리한 경험을 정리했습니다. AI가 만든 결과를 직접 확인해야 하는 이유와 다음 개선 과제를 담았습니다. 제출 전 작성자가 본인의 경험·소감을 확인해 보완하는 회고 초안입니다.

## 6. [AI 협업 기록 — 주요 대화·효과적인 프롬프트](docs/submission/AI_COLLABORATION.md)

사용자가 업무 범위와 요구사항을 정하고 AI가 화면·코드·테스트·배포·문서 작업을 도운 과정을 기록했습니다. 효과적이었던 실제 요청을 표시하고, 작업 결과와 미완료 범위를 구분했습니다. 개인정보를 제외한 대화 발췌·작업 요약이며 전체 대화 원문은 아닙니다.
