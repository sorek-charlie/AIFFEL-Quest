# 경정청구 자료 검토 도우미

회사 회계 담당자와 세무사가 기관·서류·연도별 자료를 정리하고, 5개년 잠정 계산 결과와 근거를 검토해 보고서로 저장하는 프로그램입니다.

## 1. [▶ 데모 영상 — 2분50초](https://tax-return-review-quest.pages.dev/demo/)

브라우저에서 바로 재생합니다. 로그인·회원가입 양식부터 개별 자료 첨부, 업로드 결과, Q&A, 시뮬레이션, 연도별·카테고리별·항목별 결과, 계산 근거, 2차 분석과 전문가 상담준비까지 보여줍니다. 회사는 **주식회사0000**으로 표시하고 계정·개인정보·원자료는 공개하지 않습니다.

1920×1080, 한국어 남성 AI 내레이션·자막이 포함돼 있습니다. 실제 앱 조작 후 화면 캡처를 편집했습니다. 회원가입은 양식 안내, 사용자 로그인 입력 구간은 생략했으며 전문가 회신·세액 확정은 미완료입니다. 영상 속 0원과 자료 필요는 환급 불가의 확정 결론이 아닙니다.

## 2. [▶ 프로그램 실행](https://tax-return-review-quest.pages.dev/)

**경정청구 도우미** 로그인 화면에서 회원가입하거나 기존 ID/PW로 시작합니다. 파일 업로드 → 법인 Q&A → 시뮬레이션 → 항목별 근거 검토 → 보고서 저장 순서로 사용합니다. ZIP 또는 기관·서류·연도별 개별 첨부를 지원합니다. 원자료는 해당 기기에서 처리하며 계산 금액은 전문가 확인이 필요한 잠정값입니다.

Windows에서 오프라인으로 사용하려면 이 폴더의 `경정청구.exe`를 실행하세요. 소스 실행·빌드·Cloudflare 배포 명령은 `개발_실행안내.md`에 있습니다. GitHub 저장소 주소는 제출용 소스 위치이며 프로그램 실행 주소와는 별개입니다.
