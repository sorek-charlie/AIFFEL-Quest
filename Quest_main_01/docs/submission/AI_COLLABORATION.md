# AI 협업 기록

이 기록은 현재 대화에서 확인되는 사용자 요청과 저장소 작업을 요약한 공개용 발췌본이다. 전체 원문·모든 실행 로그를 복원한 기록이 아니다. 실제 회사명, 경로, 첨부자료, 금액과 개인정보는 공개하지 않는다. 첨부문서 내용은 참고자료로 취급하고 사용자 요청과 구분했다.

## 주요 협업 사례

| 사용자 요청 · 공개용 요약 | AI가 수행한 작업 | 확인·판단 또는 남은 한계 |
|---|---|---|
| 파일 수집·법인 Q&A 이후 시뮬레이션으로 연결 | 업로드·Q&A·결과 흐름 구성 | 브라우저 업로드와 Windows 수집 연결은 기능 범위가 다름 |
| 보고서 제목 중복 제거, 미리보기를 위로 이동 | 보고서 진입부와 순서 정리 | 현재 세션 자료로 보고서 1~4 생성 |
| 소계 명칭과 연노랑 배경 통일 | 결과표와 보고서 표시 정리 | 계산 정확성 검증과 UI 검증을 구분 |
| 전문가 결과와 앱 결과 차이 재검토 | 계산 범위·부족자료·전문가 확인 필요성 검토 | 전문가 오류로 단정하지 않음; 공제 최적화 등 미완료 |
| 세무사 관련 경정청구만 남기기 | 노무사·지원금 신청 범위 제외 | 고용세액공제용 고용 증빙은 세무 입력으로 유지 |
| 실제 자료를 별도 백업하고 현재 파일·Git 이력에서 제거 | 외부 백업·공개 소스 분리·이력 정리·점검 도구 작성 | 공개 전 파일과 Git 이력 재점검 필요 |
| 기관·서류명·연도별로 한 파일씩 입력, 기타는 이름과 첨부 | 18칸 개별 입력, 기타 메타데이터, 연도 불일치 방어 | 참고 첨부를 자동계산 성공으로 표시하지 않음 |
| PRD·회고·협업 기록·가상 샘플·3분 대본 준비 | 현재 제출 자료 작성과 샘플 브라우저 검증 | 영상 녹화·배포·실제 제출은 별도 |
| 제출용 URL 새로 만들기 | 기존 인증으로 별도 Cloudflare Pages 생성, 공개 파일 48개 배포 | 실제 HTTPS 주소에서 가상 입력·보고서 저장·Reset 검증 통과; 영상·GitHub 제출은 남음 |
| ID/PW 진입·회원가입·2~3분 뒤 팝업·가입10초 후 진입 | Pages Functions·D1 기반 서버 인증, 안내 타이머·가입 카운트다운·로그아웃 구현 | 가상 계정으로 타이머·오류·세션·가입 후 업로드 검증. 실제 비밀번호는 기록·공개하지 않음 |
| 지금까지 반영한 제출자료와 영상 제작 지시서 | PRD·회고·협업 기록 갱신, 제출보고서·최신 AI 영상 지시서 작성 | 실제 MP4 제작·GitHub 업로드·제출 폼 전송은 미완료 |
| 제출할 레포지터리 URL 만들기 | GitHub 공개 저장소 생성, 회사정보 제외 점검 후 소스·문서·가상 샘플 게시 | 실제 영상 제작과 최종 제출 폼 전송은 미완료 |

## 가장 효과적인 프롬프트

개인정보가 없는 부분을 그대로 발췌했다. 원문의 오탈자는 유지했다.

> 파일 하나씩을 클릭하면 이 파일들을 하나씩 입력할 수 있도록 관련부서별 서류명별 년도등.... 하나씩 입력할 수 잇도록 해 주고, 기타는 파일명 적고, 첨부 할 수 있또록 해 줘.

구체적인 사용 행동(파일 하나씩), 분류 기준(부서·서류명·연도), 예외(기타 이름 직접 입력)가 한 번에 주어졌다. 이를 기준으로 UI와 검증 항목을 정할 수 있었다. 구현 후 기본 18칸, 기타 이름 필수, 메타데이터 표시, 연도 불일치 차단, 초기화를 브라우저에서 확인했다.

## 사람과 AI의 역할

사용자는 업무 범위·표현·첨부 방식·공개자료 제외 기준을 정하고, 실제 세무 결과의 차이를 지적했다. AI는 코드 수정, 가상 입력 구성, 자동 검증과 제출 문서 초안을 담당했다. 사용자는 최종 문서의 본인 경험·이름·주소·영상과 실제 업무 적합성을 확인한다. 세무적 정확성은 별도 전문가 기준 사례로 검증해야 한다.

## 검증 근거

`dev/tests/e2e_qa.py`, `dev/tests/single_file_intake_qa.py`, `dev/tests/submission_demo_qa.py`와 `dev/scripts/check_public_repo.py`를 재실행할 수 있다. 이번 샘플의 결과·화면·다운로드 확인은 [검증 기록](VERIFICATION.md)에 정리한다. 테스트 통과를 세법 적합성이나 실제 기관 수집 완료의 증거로 사용하지 않는다.
