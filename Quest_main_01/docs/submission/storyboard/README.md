# 10컷 사용 시나리오 이미지

[사용씬 이미지 열기](usage-storyboard-10-scenes.png)

[씬별16:9 PNG 10장과 사용 순서](scenes-16x9/README.md)도 제공합니다. 각 이미지는1920×1080입니다.

`AI영상제작.md`의 2분50초 구성을 설명하는 AI 생성 일러스트다. 실제 앱 캡처가 아니며 영상의 실제 기능 시연은 배포 앱에서 촬영한다. 장면 속 단순화된 화면·파일명·문구는 실제 UI와 다를 수 있다.

생성 도구: 내장 image_gen. 원본은 별도로 보존하고 프로젝트에 PNG를 복사했다.

생성 프롬프트 요지: 경정청구 검토 도우미의 영상용 스토리보드를 세로형2열×5행으로 제작. 흰색·연파랑 배경, 남색·파랑 포인트, 연노랑 소계, 같은 가상 사무직 인물과 노트북, 읽기 쉬운 한국어 제목과 시간대. 서비스 접속 → ID/PW 로그인 → 방문2~3분 후 가입 안내 → 가입10초 후 자동 로그인 → 기관·서류·연도별 첨부 → 기타 서류 → 법인 Q&A·검토 →5개년 잠정 결과 → 보고서·HTML 저장 →Reset·로그아웃. 실제 개인정보·비밀번호·환급 금액·정부 인증 표시는 제외. 상단에 영상 스토리보드, 하단에 실제 시연은 배포 앱으로 촬영한다는 안내 표시.
