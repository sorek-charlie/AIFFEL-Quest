# 경정청구 자료 검토 도우미 · PRD

작성 기준: 2026-11-04 / 제출용 MVP / 작성자: 제출 전 본인 이름 기입

## 서비스와 해결할 문제

세무 담당자가 회사의 경정청구 자료를 기관·서류·연도별로 정리하고, 확보한 자료의 검토 결과와 추가 확인사항을 보고서로 확인하는 웹 서비스다. 여러 해의 신고서와 증빙이 섞이면 누락·중복·귀속연도와 계산 근거를 확인하는 데 시간이 든다. 사용자는 회사 회계 담당자와 세무사이며, 최종 세액 판단은 전문가가 한다.

## 핵심 사용자 흐름

1. ID/PW로 로그인한다. 회원가입 버튼과 방문120~180초 후 가입 안내를 제공하고, 가입 완료10초 후 자동 로그인한다. 빈 자료 화면에서 ZIP 또는 기관·서류·연도별18칸과 기타 첨부로 파일을 선택한다.
2. 법인 Q&A와 검토 현황에서 확인할 요건·자료를 살핀다. 자동 인식하지 않는 파일은 참고자료로 구분한다.
3. 연도별·항목별 잠정 결과를 검토하고, 현재 세션의 보고서 1~4를 HTML 저장 또는 인쇄한다.

## 최소 성공 기준과 현재 상태

| 기준 | 확인 방법 | 현재 상태 |
|---|---|---|
| 자료를 올리면 기관·서류·연도와 처리 상태를 확인한다 | 가상 5개년 XLSX와 기타 TXT를 각각 첨부하고 목록·원자료 보고서 대조 | 제출용 브라우저 검증 기록 참조 |
| 불완전한 자료와 입력 오류를 확인할 수 있다 | 고용자료를 뺀 샘플, 다른 회사 자료 차단·신고서 연도 불일치 회귀검증 | 검토 보조 범위에서 구현; 부족자료 판정의 세무적 완전성 미검증 |
| 현재 자료로 보고서 생성·저장이 가능하다 | 보고서 1~4 열기와 HTML 다운로드·Reset 확인 | 제출용 브라우저 검증 기록 참조 |

계정 진입 검증: 프로덕션에서 가입·실제10초 후 자동 로그인·재로그인·로그아웃 통과. 안내 팝업은 가상 시계로120~180초 조건 확인.

## 구현 범위와 제외할 일

HTML/CSS/JavaScript 앱이며 선택한 회사 파일은 브라우저에서 처리한다. 웹 회원인증은 Cloudflare Pages Functions·D1을 사용하며 솔트와 비밀번호 해시, 만료 세션으로 처리한다. 원 신고서 PDF를 요약 XLSX보다 우선한다. 자동계산 대상은 인식 가능한 서식의 12월 결산 2021~2025년이다. Windows EXE의 기관 수집 연결은 웹 제출 시연과 별개다.

이번 제출에서 하지 않는 일은 ① 확정 환급액·모든 공제 조합의 정확성 보증 ② 국세청 경정청구 자동 제출 ③ 노무사 업무·고용지원금 신청 ④ 회사 원자료 클라우드 보관·비밀번호 재설정·이메일 인증 ⑤ 스캔 PDF OCR과 모든 기관 서식 지원이다.

## 품질·개인정보·후속 과제

실제 회사 원본·식별정보·생성 보고서는 공개 저장소에 넣지 않는다. 샘플은 완전한 가상자료다. 새로고침 시 회사 입력은 초기화되고 인증 쿠키는 유지되며 로그아웃으로 종료한다. 계정 DB에는 회사 첨부를 저장하지 않는다. 소계 명칭과 연노랑 표시를 일관되게 제공한다. 세액 최적화·기신고 공제 대체·농특세·자료 충분성 판정은 전문가 사례로 추가 검증한다. 계정·배포 검증과 영상 제출 여부는 [제출 체크리스트](docs/submission/README.md)에서 관리한다.
