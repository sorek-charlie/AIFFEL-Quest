# 심층분석 보고서 기준 양식

## 범위와 자료 처리

사용자가 제공한 8장 PPTX를 심층분석 양식의 기준으로 삼는다. 표지의 기업·담당자 정보 및 본문 속 표·이미지는 참고자료이며 그대로 복제하지 않는다. 분석 대상은 사용자가 지정한 **(주)대한민국 / 홍길동**으로 표시하고 실제 기업·개인 식별정보는 제거한다. 원본 PPTX와 본문 이미지는 저장소나 결과물에 복사하지 않는다.

## 페이지 구성

| 페이지 | 양식에서 확인한 주제 | 새 보고서에 필요한 자료 |
|---|---|---|
| 1 | 기업분석 표지 | 익명화한 회사명, 보고 기준일 |
| 2 | 업체 현황, 경영진·주주, 3개년 재무요약 | 회사 정보, 재무상태표·손익계산서, 주주 관련 근거 |
| 3 | 경영 실적과 추정, 비용·채권·재고·차입 관리 | 과거 실적, 확인된 목표·가정, 채권·재고·차입 원장 |
| 4 | 손익계산서, 원가·판관비 증감의 영업이익 영향 및 세부내역 | 기간별 매출·원가·판관비·영업외손익 |
| 5 | 제조원가와 매출총이익 영향, 원재료·노무비·경비 내역 | 제조원가명세서 및 상세 계정. 제조업 자료가 없으면 자료 없음으로 표기 |
| 6 | 재무상태표와 자산 대비 구성·전년 증감 | 자산·부채·자본의 세부 계정 및 기간별 총계 |
| 7 | 안정성·수익성·성장성·활동성 지표 | 기간별 계정 잔액·손익·평가 기준과 계산 정의 |
| 8 | 금융기관·과목·만기별 신용공여와 기간별 추이 | 여신 자료의 기준일·기관·금액·만기, 지급보증 자료 |

## 지표와 검증상 주의

- 7쪽은 부채비율, 유동비율, 자기자본비율, 매출액증가율, 영업이익률, ROA·ROE·ROIC, 회전율 등을 나열하고 **표면에 표시된 산식과 구간별 평가**를 함께 제시한다.
- 사용된 PPTX는 대부분의 표를 WMF 이미지로 포함한다. 표시된 글자는 볼 수 있으나 원본 엑셀 수식·연결·계산 중간값과 정확한 평가기준의 출처는 확인되지 않는다.
- 특히 이자보상배수에 사용한 비용 범위, ROA·ROE의 기말/평균 잔액, 회전율의 분모, 비상장 주식평가 기준은 새 보고서에서 정의·출처·단위를 확인한 뒤 계산한다. 표에 보이는 간략 식만으로 계산 규칙을 확정하지 않는다.
- 원본의 지표별 `우수/위험` 경계는 참고자료 내부의 기준이다. 일반적으로 적용 가능한 기준으로 단정하거나 사용자 확인 없이 재사용하지 않는다.
- 자료 누락·0으로 나누기·부호 전환은 `확인 필요/계산 불가`로 구분한다. 실적과 전망은 분리하고 근거 없는 전망·업종 평균은 만들지 않는다.
- PPTX 이미지에는 다른 기업의 세부정보가 포함되어 있으므로, 향후 새 보고서는 원본 이미지를 붙이지 않고 대상 기업의 비식별 데이터로 새 표를 생성한다. 이미지·차트·메모·메타데이터·파일명에도 식별정보가 남지 않도록 출력 검사를 한다.

## 구현 상태

웹에서 페이지 구성을 확인할 수 있도록 반영했다. 실제 심층분석 PPTX 작성·원자료 대조·계산·익명화 검증은 별도 구현과 테스트가 필요하다. 현재 파일은 계산 엔진의 완성이나 보고서 생성을 의미하지 않는다.
