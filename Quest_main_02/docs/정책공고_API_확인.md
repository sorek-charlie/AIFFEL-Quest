# 정부지원사업 공고 API 조사

확인일: 2026-11-17. 기업마당, K-Startup, 판판대로의 개발계정 승인과 실제 조회를 확인했다. `data/secrets/data-go-kr.dpapi`는 현재 Windows 사용자 계정에 묶여 암호화된 인증키이며 Git 제외 대상이다.

매일 08:30 세 출처 수집과 매주 월요일 09:00 주간 Telegram 발송을 Windows 작업 스케줄러 및 Codex 앱 자동화에 등록했다. 중복 수집은 파일 잠금·일별 성공 상태, 중복 발송은 SQLite 주별 기록으로 방지한다. 로그인 시 놓친 당일 수집을 실행하고 월요일 09:00 이후 로그인한 경우 로그인 5분 후 주간 발송을 확인한다. 놓친 예약은 실행 가능 시 시작하며 실패 시 5분 간격 3회까지 재시도한다. PC 로그인·네트워크·기존 봇 설정이 필요하다. 이전 발송 결과가 불명확하면 자동 재발송하지 않는다.

기존 ‘나의 로컬 AI 비서’ 봇과 허용된 개인 대화방은 읽기 전용 API로 확인했다. 실제 예약 시각의 Telegram 발송은 아직 검증하지 않았다. 주간 메시지는 최신 수집자료에서 공고 제목·지역·기한·링크 최대 7건 및 정부24 혜택 후보 최대 2건을 코드로 구성하며 LLM 요약은 아직 연결되지 않았다. K-Startup은 모집 상태 Y 기준, 판판대로는 당해연도 기준이다. 응답에 날짜·지역이 불명확하면 확인 필요로 남기고, 실패 출처를 보고서에 표시한다.

## 정부24 혜택 후보

[행정안전부 대한민국 공공서비스(혜택) 정보](https://www.data.go.kr/data/15113968/openapi.do)의 승인과 실제 수집을 확인했다. 전체 서비스에서 사용자 구분이 법인 또는 소상공인을 포함하는 항목을 조회하고 서비스 ID로 중복 제거한다. 해당 구분은 개인, 복지시설 또는 단체도 포괄할 수 있어 실제 중소기업 지원 자격으로 단정하지 않는다. 혜택 정보는 공고와 구분하여 `data/policy-live/04_정부24_공공서비스_혜택.md`에 저장한다. 소관기관에 따른 서울·경기 분류는 신청 가능 지역의 확정이 아니다.

실제 확인: 공식 API에서 `resultCode=00`, `NORMAL_SERVICE`, 첫 페이지 5건, 총 1,333건을 응답받았다. 총건수는 호출 시점의 값이다. 이 작업 환경의 일반 실행은 DNS 접속이 제한되어 공식 API에 대한 별도 네트워크 권한으로 시험했다. 앱 자체의 자동 수집 환경에서 같은 연결이 보장된다는 뜻은 아니다. 인증키와 요청 URL은 기록하지 않는다.

2026-11-17 15:07 KST에 전체 페이지 수집·분류를 실행했다. 기업마당 공고 1,333건, ID 중복 0건이며 제목의 지역 접두어 또는 명시적 전국 태그에 근거해 서울 37, 경기 132, 전국 2, 기타 지역 708, 지역 확인 필요 454건으로 구분했다. 지역이 불명확한 454건은 전국 전체 목록에서 확인하며 서울·경기 목록에는 임의로 포함하지 않는다. API의 마감일을 해석할 수 없으면 상시접수나 마감 여부를 임의 확정하지 않는다.

일별 수동 확인 명령은 프로젝트 루트에서 `.\.venv\Scripts\python.exe -m briefings.policy_jobs`이다. 인증키를 복호화할 수 있는 같은 Windows 계정과 API 네트워크 접근이 필요하다. 결과는 `data/policy-live/`에 저장하고 새 실행으로 갱신한다. 개별 API 호출 중 페이지가 누락되거나 전체 건수가 변하면 해당 출처는 실패로 표시하고 나머지 성공 자료만 저장한다. 하루 세 출처 모두 성공하기 전에는 성공 상태를 확정하지 않는다.

## 1차 연결 추천: 공공데이터포털 기업마당 공고 조회

- [중소벤처기업부_중소기업 지원사업 공고 조회 서비스](https://www.data.go.kr/data/15157820/openapi.do): 중앙부처·지자체·유관기관 지원사업. 공고ID·제목·원문 URL·소관 및 수행기관·개요·신청기간·지원대상·해시태그 등.
- REST, JSON/XML, 무료. 공공데이터포털에서 해당 서비스에 별도 활용신청이 필요하며 개발단계 자동승인, 운영단계 심의승인으로 표시된다. 개발계정 신청 가능 트래픽 10,000으로 표시되므로 실제 적용 단위·제한과 승인은 신청 화면에서 재확인한다.
- 기본 서비스 주소 `https://apis.data.go.kr/1421000/bizinfo`. 실제 세부 호출 주소는 활용신청 후 명세에서 확인한다. 필수 `serviceKey`, 선택 `dataType`, `pageNo`, `numOfRows`, `searchLclasId`, `hashtags`, `pblancId`, `registDe` 등. 신청 후 인코딩/디코딩 키와 클라이언트 인코딩을 맞추고 실제 응답 구조·페이지네이션을 검증한다.
- 표기된 공간범위 전국, 시간범위 당해연도, 갱신주기 일간. 해시태그만으로 지역·전국 대상의 완전한 분리가 보장되지는 않는다. 원문 정보가 부족한 경우 지역·자격을 확인 필요로 둔다.
- 데이터 페이지는 공공누리 제3유형(출처표시·변경금지)으로 표기한다. 요약·변형 이용에 적용되는 범위는 제공기관에 확인하고, 우선 원제목·원문 링크 및 출처를 유지한다. [공공누리 제3유형](https://www.kogl.or.kr/info/licenseType3.do).

## 2차 연결 후보: K-Startup

- [창업진흥원_K-Startup 조회서비스](https://www.data.go.kr/data/15125364/openapi.do)는 창업지원 공고·기간·대상·분야 등의 정보. 공공데이터포털의 **해당 서비스도 각각 활용신청**한다. 무료, JSON/XML, 제공 페이지는 갱신주기 실시간으로 표기한다.
- `serviceKey`, `page`, `perPage`, `returnType` 및 지원지역·모집진행 여부 필터를 명세에 표시한다. 기본 서비스 URL은 `https://apis.data.go.kr/B552735/kisedKstartupService01`; 실제 공고조회 세부 호출 경로와 승인·한도·갱신 지연은 신청 후 테스트한다. [공식 검색 샘플](https://nidview.k-startup.go.kr/view/public/kisedKstartupService/announcementInformation).
- 저장본에 기업마당 외 K-Startup 공고도 있으므로 기업마당만으로 동일한 범위를 보장하지 않는다. 서로 다른 ID는 원문과 기관·제목·기간을 비교하고 불확실하면 따로 보존한다.

## 선택 경로: 기업마당 직접 API

- [기업마당 지원사업정보 API](https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi) 사용신청에서 별도 인증키 `crtfcKey`를 발급받는다. 공공데이터포털의 `serviceKey`와 혼용하지 않는다.
- GET `https://www.bizinfo.go.kr/uss/rss/bizinfoApi.do`, 선택 인자 `dataType`, `searchCnt`, `searchLclasId`, `hashtags`, `pageUnit`, `pageIndex`가 안내된다. 공식 설명에는 `searchCnt` 생략 또는 0이 전체 데이터라고 되어 있으나, 실제 페이징·상한·응답은 키 발급 후 검증한다.
- 신청 창은 기업명·신청자명·이메일·전화·시스템명과 시스템 IP/URL 입력을 안내한다. 로컬 PC의 동적 IP와 URL 기재 가능 여부는 발급처에 확인한다. 개인정보·동의·신청은 사용자가 진행한다. API 키는 채팅에 공유하지 않는다.

## 추가 후보

- [판판대로 지원사업 정보 제공 서비스](https://www.data.go.kr/data/15163956/openapi.do): 지원대상·지역·모집기간·URL을 제공하는 보완 후보. 본문은 일 1회 갱신이라고 하지만 메타데이터는 실시간으로 기재되어 있어 실제 갱신 시간은 별도 확인이 필요하다.
- [기업마당 행사정보 API 안내](https://bizinfo.go.kr/apiList.do): 교육·세미나·전시 등 행사는 지원사업 공고와 별도 API다.
- 서울·경기 개별 수집원의 API와 제공 범위는 아직 확인되지 않았다. 기업마당 지자체 공고가 양 지역의 모든 공고를 망라한다고 가정하지 않는다.

## 사용자 설정 순서

1. 공공데이터포털 가입·로그인 → 기업마당 지원사업 공고 조회 서비스의 **활용신청** → 승인 상태와 일반 인증키를 확인한다.
2. 같은 포털에서 K-Startup 조회서비스도 활용신청한다. 보통 포털 계정의 키를 사용하더라도 서비스별 활용 권한은 별도로 확인한다.
3. 기업마당용 공공데이터포털 키는 Windows 사용자 계정에 묶인 DPAPI로 암호화 저장했다. 다른 Windows 계정이나 PC에서는 복호화할 수 없고 동일 사용자로 실행해야 한다.
4. 세 API 모두 실제 호출했다. 전국·서울·경기별 목록 및 실패 표시를 구현했다. 출처 간 유사한 공고는 별도로 표시될 수 있다.
5. PC가 꺼져 있거나 Windows에 로그인하지 않으면 로컬 예약 작업이 실행되지 않는다. 지연 실행 조건을 위에 명시했다.
