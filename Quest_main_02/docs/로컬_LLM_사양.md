## 운영

정기 보고가 실행될 때 모델 서버가 꺼져 있으면 프로그램이 로컬 모델을 시작한다. 서버 시작 잠금은 중복 기동을 막는다. 로그: `output/local-model/server.log`. 모델 서버나 인터넷·Telegram이 실패하면 정상 발송으로 표시하지 않는다. 2026-11-17에 간단한 로컬 모델 응답을 약 6초에 확인했으나, 이는 단일 시험이며 모든 보고서의 처리시간을 보장하지 않는다.

모델 파일은 프로젝트 밖 기존 로컬 AI 비서의 `.runtime/models`에 있다. 해당 파일·가상환경·비밀키를 삭제하거나 이동하면 연결이 끊어질 수 있다.
