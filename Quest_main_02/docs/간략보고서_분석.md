# 간략보고서 참조 분석

참조는 `#크레탑분석_김영훈.pdf` 7쪽 스캔. 원본 엑셀 수식이나 셀 연결을 포함하지 않는다. 페이지별 육안 확인 결과다.

| 쪽 | 구성 | 필요한 자료 |
|---|---|---|
| 1 | 표지, 분석 기준연도 | 기업명·연도·작성일 |
| 2 | 회사·경영진·주주, 3개년 재무상태 및 손익 요약 | 기본·주주정보, 연도별 재무제표, 주식 평가 근거 |
| 3 | 제조원가의 손익 영향, 원가명세 | 제품매출, 원재료·노무비·경비 |
| 4 | 판매비 손익 영향, 손익계산서 | 매출·원가·판관비·인건비·경비 |
| 5 | 3개년 재무상태표 상세 | 자산·부채·자본 세부계정 |
| 6 | 기관·과목·만기별 신용공여 | 금융기관별 여신·보증, 잔액·만기·기준일 |
| 7 | 자문가 소개 및 업무 | 포함 여부 미정, 타인의 연락처를 재사용하지 않음 |

제조업 원가명세가 없는 유통·서비스 기업은 수치를 만들지 않는다. 자료가 없으면 `자료 없음`으로 표시하고 대체 구성은 보류한다. 원본 수식·참조 관계·출력 형식은 엑셀 원본 확인이 필요하다.
