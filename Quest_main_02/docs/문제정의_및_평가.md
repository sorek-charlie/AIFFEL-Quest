# 문제 정의 및 평가 계획

## 문제 정의
- **도메인:** 중소기업의 경영 보고, 회의 기록, 문서 검토와 정기 정보 수집.
- **현행 문제:** 서로 다른 문서·음성·이미지·영상에서 자료를 옮기고 요약하거나 재무 보고서를 만드는 과정이 반복된다. 현재 수작업 시간과 오류율은 미측정이다.
- **대상:** 중소기업의 업무 담당자와 보고서를 읽는 대표·경영진. 담당자의 세부 직무는 미확정.
- **개선 가설:** 원문 추출·STT·요약을 연결하고 근거를 병기하면 작성자 검토 시간을 포함한 전체 작업 시간을 줄일 수 있다.
- **성공 기준:** 업로드가 시작된 뒤 사용자가 결과를 열 수 있을 때까지 180초 이내이고, 같은 업무의 데모 미리보기와 비교해 구성·핵심 내용·원자료 근거가 동일 수준인 경우에 합격이다. 시간 초과나 품질 미달은 미달로 기록하고, 실측값 또는 품질 판정이 빠지면 미검증으로 기록한다. 검토·수정을 포함한 전체 업무 시간과 항목 정확도는 이 기준과 별도로 비교한다. 재무 계산은 원자료 대조와 독립 검산을 적용한다.

## 노드09 연결
| 병목 유형 | 이 프로젝트 사례 | 측정 후보 |
|---|---|---|
| 입력·전사 | 음성/동영상 STT, 스캔 OCR | 전사 오류와 전체 수정 시간 |
| 검색 | 정책 공고·이슈 출처와 문서 근거 찾기 | 상위 결과의 적합성·출처 정확도 |
| 분류·배분 | 회의 결정·할 일·정책 지역 분류 | 항목 일치·누락·잘못된 담당자 |
| 검사·판독 | 재무 수치와 합계 검산 | 계산 및 원문 대조 일치 |

사람의 기준이 불명확하거나 정답 기록이 없는 항목은 먼저 평가 기준을 정한다. 되돌리기 어려운 판정은 사람에게 남긴다. 개인정보 외부 전송 가능 여부와 라이선스는 점수와 별개의 제외 조건이다.

## 비교 실험 절차
1. 실제 또는 허가받은 자료 10~20건을 준비하고 개인정보 제거·보관 위치·사용 허가를 확인한다. 음질이 나쁜 녹음, 흐린 스캔, 표·다단 문서 등 어려운 사례를 포함한다.
2. 모델 실행 전 정답(회의 안건·결정·담당자·기한, 요약 핵심과 원문 근거)을 독립적으로 작성한다.
3. 동일한 자료로 **수작업 기준선**을 측정한다. 시작부터 검토 완료까지 시간과 오류·누락을 남긴다.
4. 후보: 사람의 수작업, OCR/STT만의 전사 결과+수작업 정리, OCR/STT+LLM. 모델명·버전·CPU/GPU·설정·입력 유형·실행 시간을 기록한다. 유료 후보는 자료 외부 전송 허용 및 라이선스 확인 후 별도 평가한다.
5. 문서 요약의 사실·수치·근거, 회의록의 결정·담당자·기한을 정답과 비교한다. 담당자·기한을 지어낸 건은 별도 기록한다. 영상은 현재 음성만 처리되며 화면 속 자료는 평가 범위 밖이다.
6. 성공/실패와 원인, 재현 명령과 화면 자료를 기록한다. 표본 부족, 오디오·영상 오류, PDF 내부 이미지/표 인식 한계도 기록한다.

## 현재 확인된 것
가상 샘플로 브라우저 출력과 Markdown 저장을 시연할 수 있다. 텍스트·PDF·이미지 추출, 가상 합성 음성과 영상의 Whisper tiny 전사는 환경별 실행 검증 대상으로 따로 기록한다. **실제 사용자 업무 데이터의 AI 성능과 시간 단축은 아직 측정하지 않았다.**


## 과제 제출용 성능 측정 기록

| 확인한 구간 | 실행 조건 | 측정 결과 |
|---|---|---:|
| 재무 원자료 추출·정규화·검산 | 동일한 PDF 2개와 ZIP 1개, 합계 1,438,506바이트, 같은 PC에서 5회 실행한 중앙값 | 2,016.63ms |
| 검산 결과 재사용 | 같은 5회의 메모리 조회와 복사, 원래 정규화 결과와 동등성 확인 | 0.583ms |

측정은 서버 함수를 직접 실행해 `perf_counter`로 했다. 업로드, AI 네트워크 호출, PDF 생성, 전송 및 검토 시간은 이 두 구간의 측정 범위 밖이다. 모의 브라우저 실행에서 한 번만 추출하고, 텔레그램 전송 대기 중에 PDF를 내려받았다. 180초에 데모 품질 동일 수준이면 합격하고, 180.01초나 품질 미달이면 미달하는 경계값을 테스트했다. 실제 복합 자료가 전부 180초 안에 데모 수준을 충족하는지는 미검증이다.

제출용 실제 평가에서는 입력 유형·파일 크기·영상 길이·난이도를 기록한다. 업로드 시작, 첫 PDF 열기 가능, 외부 발송 완료 시점을 각각 기록하고 구성·핵심 내용·근거를 데모와 대조한다. 180초 초과, 검증되지 않은 AI 의견, 지원하지 않는 자료 유형과 실패를 결과에 남긴다.
