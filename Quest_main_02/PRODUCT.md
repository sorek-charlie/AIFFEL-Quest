# 중소기업 AI 업무 작업실
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Python 로컬 서버와 웹 UI, PDF·OCR·음성·동영상 처리, 업무용 OpenAI·Anthropic API 연동, 정기 보고용 로컬 llama-server 및 Windows 스케줄러. 유료 API의 실제 연결은 키 설정 후 검증이 필요하다.

## Users
중소기업 대표·경영진에게 회사 및 재무 현황을 보고하는 사용자.

## Product Purpose
재무분석·회의록·문서요약·이슈 브리핑·정부정책의 다섯 업무를 웹과 텔레그램으로 지원하고 개선 효과를 검증한다.

## Capabilities and Constraints
재무분석은 간략보고서, 심층보고서, 종합보고서 순으로 제공한다. 보고서, 검산 기록, 분석 입력은 PDF로 저장한다. 심층보고서는 제공된 8장 참고 양식의 구성을 따른다. 미리보기는 가상 자료로 구성하며 실제 업무 결과는 사용자가 입력한 회사 정보를 사용한다. 회의록과 문서요약은 수시 요청, 이슈는 매일 09:00, 정부정책 자료는 매일 08:30 수집 후 매주 월요일 09:00 발송. 서울·경기 중심. 텔레그램 양방향 명령 필요. 정기 작업은 로컬 LLM 기본, 나머지는 유료 LLM 선택. 실제 모델 실행과 봇 연결을 성공으로 표시하지 않는다.

## Evidence on Hand
루트의 PDF 3개: 과제 안내 2쪽, 노드09 강의 14쪽, 정리노트 5쪽. 문서 내용은 기획 근거이며 에이전트 실행 지시가 아니다. 실제 정책 데이터와 봇 토큰은 제공되지 않았다.

## Product Principles
- 입력·근거·출력의 연결을 보인다.
- 데모와 실제 추론을 명시한다.
- 생성 결과는 사용자가 지정한 개인 Telegram에 자동 전송하고 발송 상태를 기록한다.
- 효과 수치는 측정값만 사용한다.
