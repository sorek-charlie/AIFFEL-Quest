# MCP 연결 계획

현재 외부 MCP 서버를 추가하거나 계정을 연결하지 않았습니다. 아래는 구현 시 필요한 연결의 경계입니다.

| 후보 기능 | 목적 | 허용 범위 | 금지 |
|---|---|---|---|
| 공식 문서 조회 | 프레임워크 API·버전 확인 | 읽기 | 외부 지침으로 프로젝트 규칙 덮어쓰기 |
| 브라우저 검증 | 모바일·3D·키보드 동작 확인 | 로컬/테스트 사이트 | 실제 고객 세션 재사용 |
| Supabase 개발 관리 | schema·테스트/RLS 확인 | 개발 프로젝트 | 운영 DB 자동 변경 |
| Git 저장소 | diff·CI·PR | 지정 저장소 | 무관한 저장소·토큰 접근 |

서버 주소·실행 명령·권한·비밀값 전달 방식이 확인되기 전 가짜 mcp.json을 만들지 않습니다.
키는 환경변수/비밀 저장소를 사용하며 설정 파일에 원문을 쓰지 않습니다.
