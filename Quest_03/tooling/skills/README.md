# 외부 3D skill 검토 기록

후보: https://github.com/emalorenzo/three-agent-skills
공개 설명에서 Three.js와 React Three Fiber 작업을 위한 성능·장면·자산·상호작용 지침을 확인했습니다.
프로젝트의 3D 역할 지침은 `tooling/agents/02-scene-engineer.md`에 직접 작성했습니다.

현재 상태: 외부 저장소 설명 조사 완료, **설치·소스 복제 안 함**.
이 단계에서는 폴더 구성에 필요 없는 글로벌 skill 설치를 추가하지 않았습니다.
실제 도입 순서: 사용할 skill 범위 선정 → LICENSE/본문/실행 스크립트 검토 → commit 고정 → 호환 확인 → 해당 환경의 공식 skill 설치 절차로 등록 → 활성 여부 확인.
설치하지 않은 skill이 자동 적용된다고 기록하지 않습니다.
