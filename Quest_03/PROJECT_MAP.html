01. 사용 환경은 나누고, 일정 데이터는 하나로

OWNER · DESKTOP / 3D

개인 일정 관리

2D·3D 주간 보기, Todo, 일정 편집, 공개 가능 시간, 요청 승인함. 일정은 서버와 DB가 관리하고 3D는 표현에 집중합니다.

GUEST · MOBILE / SIMPLE

공유 URL 예약

날짜 → 시간 → 연락처 → 승인 대기. 앱 설치·3D 조작 없이 사용합니다. 개인 일정 제목과 메모는 공개하지 않습니다.

02. 코드가 연결되는 구조

apps/webowner · public · features · scene
→
apps/apiHTTP → 유스케이스 → 저장 어댑터
api/infrastructure저장 인터페이스를 구현하는 DB 어댑터
→
databaseSQLite / Supabase 중 하나 선택

공유 packages: domain · contracts · ui · design-tokens. API가 domain·ports와 DB 어댑터를 연결합니다. 브라우저 → DB 직접 접근은 없습니다.

고객 신청승인 대기본인 승인 + 충돌 재검사DB 원자적 저장약속 확정
같은 시간에 두 요청이 들어와도, 일정 점유와 승인 상태를 한 번에 저장해 중복 확정을 막도록 설계했습니다. 현재는 설계 단계이며 기능 실행 테스트는 아직 하지 않았습니다.
