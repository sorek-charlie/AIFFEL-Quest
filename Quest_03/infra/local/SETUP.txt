ORBIT 0.2 · PC + Android

PC: Quest_03의 ORBIT-Scheduler.exe 실행. dist/ORBIT-Scheduler 폴더를 유지하세요.
처음에는 비밀번호를 직접 설정합니다. 초기 비밀번호는 정해져 있지 않습니다.
로그인 화면에서 비밀번호 변경이 가능합니다. 변경에는 현재 비밀번호가 필요합니다.
로그인 직후 오늘 시간별 일정·날짜 지정 할 일·프로젝트 브리핑이 뜹니다.
입력 메뉴의 프로젝트 / 일정 / 할 일을 선택해 구분 입력하세요.
할 일 날짜를 지정하면 해당 날짜 브리핑에 표시됩니다. 날짜 미지정은 별도 안내합니다.
프로젝트에는 기간과 상태를 지정하고 일정·할 일을 연결할 수 있습니다.
오늘 브리핑 보기로 다시 열 수 있으며 Esc 또는 닫기로 닫습니다.

입력 메뉴: 직접 입력 / 고객 신청 Confirm / 문서·이미지 추출 / 텍스트 / 검토함
연동 메뉴: Gmail / Google 일정 / Android·카카오톡 안내 / ICS
강제 일정 반영: 연결된 소스 즉시 확인. 충돌 검사는 계속 적용됩니다.

Gmail/Google 일정은 연결 전에는 동작하지 않습니다.
Google Cloud에서 Gmail API와 Calendar API를 활성화하고 Desktop OAuth client를 발급한 후
앱의 입력·연동 화면에 ID/시크릿을 입력하고 charlie.sungjin@gmail.com으로 인증하세요.
Gmail은 받은편지함 최근 7일을 1시간마다 Todo로 추가합니다.
Google 일정은 1분마다 확인합니다. PC 프로그램이 켜져 있어야 합니다.

Android: ORBIT-Android.apk를 휴대폰에 복사하고 직접 설치합니다. Android 8 이상.
기기에서 초기 비밀번호 설정 → 알림 접근 권한 및 캘린더 권한 허용 → 카카오톡 알림 수집 켜기.
지정 계정의 Google 캘린더가 기기에 동기화되어 있어야 합니다.
알림에서 추출한 후보의 날짜/시간을 반드시 확인한 후 Google 일정에 저장하세요.
기기 Google 동기화가 끝나면 PC가 가져옵니다. USB-C 상시 연결은 필요하지 않습니다.
실제 휴대폰/Google 계정의 종단간 연동은 아직 검증하지 않았습니다. APK는 개발 서명판입니다.

지원 업로드: TXT MD CSV JSON ICS PNG JPG JPEG BMP, 파일당 8MB 이하.
이미지는 Windows OCR을 사용합니다. PDF/Word는 텍스트로 저장해 가져오세요.
반복 ICS 및 Asia/Seoul/UTC 외 시간대는 Google 연결을 이용하세요.
카카오톡 전체 대화 조회는 지원하지 않습니다. 알림에 보이는 내용만 보조 앱에서 처리합니다.
웹에서 즉시 푸시 갱신은 공개 HTTPS 서버 배포가 필요한 후속 범위입니다.

외부 관리자 터미널: https://orbit-appointments-quest03.cherrysocute9.chatgpt.site/owner
기존 PC 비밀번호로 휴대폰에서 로그인하세요. 이 업데이트 뒤 PC 프로그램을 재시작하세요.
PC 프로그램과 인터넷을 켜 두어야 일정 조회/저장/승인이 동작합니다. 절전/종료 시 연결 대기를 표시합니다.
고객 신청: https://orbit-appointments-quest03.cherrysocute9.chatgpt.site/booking
설정에서 공유를 활성화하고 이 링크만 고객에게 보내세요. 30분 단위 미팅/목적/방문처를 받습니다.
PC 원본은 SQLite, 외부 HTTPS 요청은 클라우드 Worker/D1 암호화 중계입니다.

본문/입력 23~28px와 자체 제공 Pretendard 글꼴을 적용했습니다.
