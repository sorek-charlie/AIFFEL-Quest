ORBIT Scheduler · Windows 로컬 실행판

1. ZIP 파일을 폴더 전체로 압축 해제합니다.
2. ORBIT-Scheduler.exe를 더블 클릭합니다.
3. 브라우저에 개인 일정 화면이 열립니다. 실행 창은 켜 두세요.
4. 실행 창에서 '프로그램 종료'를 누르면 서버가 종료됩니다.

EXE만 따로 옮기지 마세요. app / runtime 폴더가 함께 있어야 합니다.
Node.js 설치는 필요 없습니다. Windows .NET Framework 4.x를 사용합니다.
서명되지 않은 자체 빌드이며 Windows에서 실행 확인 화면이 나올 수 있습니다.

저장 위치: %LOCALAPPDATA%\ORBIT Scheduler\data
앱을 종료하거나 새 버전을 설치해도 저장 데이터는 유지됩니다.
백업 시 프로그램을 종료하고 data 폴더 전체(DB와 .key 포함)를 복사하세요.

할 일 추가/수정/완료/삭제, 일정 추가/수정/취소,
예약 시간 설정, 고객 신청, 승인/거절/취소, 상태 확인을 지원합니다.
핸드폰 발신 번호 기본값: 010-9228-6269 (설정에서 변경 가능)
문자/전화/이메일 서비스는 연결되어 있지 않습니다. 실제 발송 기능은 없습니다.
공간 보기는 CSS 원근 표현입니다. 2D로 언제든 돌아갈 수 있습니다.

현재 버전은 이 PC 전용입니다. 휴대폰에서 접속하는 인터넷 공유,
Supabase 인증/RLS/클라우드 저장, WebGL 3D는 아직 구현하지 않았습니다.
공개 예약 화면은 설정에서 활성화한 뒤 '예약 페이지 열기'로 확인합니다.
개인 화면을 다시 열 때는 실행 창의 '개인 화면 열기'를 누르세요.
실제 연락처나 DB를 소스/제출 ZIP에 추가하지 마세요.
