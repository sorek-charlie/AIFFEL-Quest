# 성능·접근성 목표

| 항목 | 초기 목표 | 확인 방법 |
|---|---|---|
| 고객 페이지 | 3D JS·모델 다운로드 0 | 네트워크·번들 분석 |
| 모바일 선택 | 한 화면 한 주요 결정, 최소 44px 조작 영역 | 360px 너비·키보드·터치 |
| 개인 3D | 정지 중 불필요한 연속 렌더 억제 | 프레임·CPU 측정 |
| 데이터량 | 우선 주간 200개 일정에 사용 가능 | 동일 테스트 장치에서 프레임·입력 지연 기록 |
| DPR | 초기 상한 1.5 제안 | 저사양 장치 비교 |
| 대체 화면 | WebGL 실패 즉시 2D 선택 제공 | 강제 context loss 테스트 |
| 글자·포커스 | 텍스트 대비·초점 표시 검증 | 자동 검사+수동 검사 |

수치는 프로젝트 목표이며 측정 결과가 아닙니다. 기기·브라우저·데이터량을 기록한 뒤 실제 기준을 조정합니다.
