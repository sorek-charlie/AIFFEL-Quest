# 주요 실패·위협과 검증

| 위험 | 방어 | 필요한 증거 |
|---|---|---|
| 타 사용자 ID로 CRUD | 세션 actor·RLS·FK owner 일치 | A로 B 데이터 read/update/delete 거부 |
| 동시에 두 건 승인 | owner 잠금·구간 제약·원자적 커밋 | 같은 슬롯 병렬 승인 중 1건 성공 |
| 일정 추가와 승인 경쟁 | 같은 점유 변경 경계 | 이벤트 생성+승인 경쟁에도 중복 없음 |
| 공개 API 정보 유출 | public DTO 필드 허용 목록 | 제목·메모·이메일 없음 |
| 반복 요청·자동 신청 | 멱등성·rate limit·입력 제한 | 중복 재전송 1건, 초과 요청 제한 |
| 상태 링크 추측/누출 | 256bit 랜덤 capability·해시 보관·만료 | 순차 ID로 조회 불가, 로그에 토큰 없음 |
| 프런트 키 노출 | 서버 환경변수·번들 검사 | secret 식별자/값이 bundle에 없음 |
| 백업 실패 | 별도 백업·복구 리허설 | 복원 후 행 수·권한 확인 |
| 공개 시간 오래됨 | 승인 시 최신 상태 재검사 | 과거 슬롯 선택은 명확한 충돌 응답 |

실제 고객 입력은 개인정보입니다. 이메일/메모는 최소 수집하고 공개 응답·로그·과제 영상에서 숨깁니다.
보존 기간은 구현 전 설정 항목으로 확정합니다. 임의의 법정 보존기간을 가정하지 않습니다.
