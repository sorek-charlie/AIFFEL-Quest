# 빈 시간 계산 정책

## 입력

소유자 시간대, 주간 가능 시간, 날짜별 예외, 미팅 유형(길이·step·앞뒤 버퍼), active 점유, 현재 서버 시각, 조회 기간입니다.
사용자가 설정하기 전의 제안 기본값은 평일 09:00~18:00, 길이 30분, step 30분, 최소 2시간 전 신청, 최대 30일 뒤입니다. 공개는 기본 꺼짐입니다.

## 계산 순서

1. 조회 범위는 최대 31일로 제한합니다. 공개 slug와 미팅 유형의 활성 상태를 확인합니다.
2. 소유자 시간대에서 날짜별 가능 구간을 만들고, 날짜 예외가 있으면 해당 날짜의 주간 규칙을 대체합니다. 휴무는 빈 구간입니다.
3. timezone을 적용하여 UTC instant로 바꿉니다. DST 중복/누락은 time-model 정책을 따릅니다.
4. 미팅 start를 step 단위로 순회하고 앞뒤 버퍼까지 가능 구간에 들어오는 후보만 남깁니다.
5. 기존 active 점유의 effective interval과 겹치는 후보, 사전시간·최대기간을 위반하는 후보를 제외합니다.
6. 결과는 start/end/timeZone으로만 반환합니다. 사유·일정 제목·다른 고객 이름은 전송하지 않습니다.

pending 신청은 점유를 만들지 않습니다. 화면의 빈 시간은 조회 시점의 결과이며 신청과 승인에서 다시 검사합니다.
신청 뒤 주최자가 규칙을 바꾸면 승인 시 새 규칙을 적용하고, 불일치는 SLOT_UNAVAILABLE로 설명합니다.
첫 버전의 복잡한 반복 일정은 미지원입니다. 주간 가능 규칙과 개별 일정으로 구현합니다.
