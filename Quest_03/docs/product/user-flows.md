# 사용자 흐름과 화면

| 사용자 | 경로 | 필요한 화면 | 실패/빈 상태 |
|---|---|---|---|
| 소유자 | /owner/tasks | Todo 목록·추가·편집 | 빈 목록, 저장 실패·재시도 |
| 소유자 | /owner/calendar | 2D/3D 주간·일정 상세 | WebGL 실패→2D, 충돌→다른 시간 |
| 소유자 | /owner/requests | 대기함·요청 상세·승인/거절 | 만료, 다른 승인으로 충돌 |
| 소유자 | /owner/availability | 요일·휴무·미팅 유형·공유 | 아직 공개 안 함, 잘못된 시간 범위 |
| 고객 | /book/:slug | 날짜→시간→연락처→요청 | 비공개 링크, 가능 시간 없음 |
| 고객 | /booking/status | capability로 최소 상태 조회 | 만료/무효, 다시 요청 안내 |

고객 입력: 이름, 연락 이메일, 짧은 요청 메모(선택), 시간대. 전화번호 등 추가 정보는 요구가 생길 때만 추가합니다.
‘접수’와 ‘확정’의 제목·버튼·상태 색을 일관되게 구분합니다. 자동 메일을 아직 연결하지 않았다면 ‘메일을 보냈다’고 표시하지 않습니다.
상태조회 capability는 URL fragment로 전달하고 브라우저가 POST 본문으로 교환합니다. 서버 access log에 query token이 남지 않게 합니다.
링크를 가진 사람에게 최소 상태만 공개되므로 연락처/메모를 응답하지 않고 Referrer-Policy를 설정합니다.
