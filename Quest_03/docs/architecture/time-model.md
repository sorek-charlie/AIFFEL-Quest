# 시간·시간대·구간 모델

- 예약·일정 시작/종료는 UTC instant, 설정과 공개 표시는 IANA timezone으로 관리합니다. 기본 표시 시간대는 Asia/Seoul입니다.
- PostgreSQL은 timestamptz, SQLite는 UTC epoch milliseconds 정수 사용안입니다. API는 Z를 포함한 ISO8601 문자열로 전송합니다.
- 구간은 [start,end)입니다. 10:00~11:00과 11:00~12:00은 버퍼가 없으면 인접하며 충돌하지 않습니다.
- 충돌 식은 `a.start < b.end && b.start < a.end`입니다. 검사에는 준비·정리 시간을 포함한 effective interval을 씁니다.
- 주간 가능 시간은 소유자 지역 시각으로 저장합니다. 계산 범위 날짜의 timezone 규칙으로 UTC 변환합니다.
- DST로 존재하지 않는 지역 시각은 슬롯을 만들지 않습니다. 중복 지역 시각은 offset이 다른 두 instant로 구분하고 화면에 시간대/offset을 표시합니다.
- 종일 일정은 소유자 시간대의 해당 날짜 시작~다음 날짜 시작으로 계산합니다. 항상 24시간이라고 가정하지 않습니다.
- ‘하루 후’를 정할 때 86,400초를 무조건 더하지 않습니다. Clock을 주입해 만료·사전시간을 테스트합니다.

시간 유틸리티 의존성은 구현 시 고르고 시간대 테스트를 통과시킵니다. 브라우저의 암묵적 로컬 파싱에 맡기지 않습니다.
