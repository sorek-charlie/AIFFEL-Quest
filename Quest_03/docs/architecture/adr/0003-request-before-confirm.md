# ADR 0003 · 승인 전에는 일정 미확정

상태: 설계 채택 / 2026-10-29

사용자 요구: 고객이 내 빈 시간에 요청하고, 내가 confirm하면 약속이 바인딩된다.
결정: pending은 장기 점유하지 않는다. 같은 슬롯의 여러 신청은 가능하나 확정은 충돌 방어 후 하나만 가능하다.
승인 시 최신 규칙·만료·점유·요청 버전을 검사한다. 승인과 일정 점유 생성은 하나의 트랜잭션이다.
경쟁에서 밀린 pending은 자동 확정/자동 거절하지 않는다. 승인 시 409 SLOT_CONFLICT를 반환하고 소유자가 거절 또는 새 요청을 안내한다.
대안: 짧은 hold는 추후 도입 가능하지만 지금은 hold 만료와 악용 방어의 복잡성을 추가하지 않는다.
