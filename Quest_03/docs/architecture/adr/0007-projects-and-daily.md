# 0007 · 프로젝트와 로그인 브리핑

프로젝트는 owner에 속한 별도 엔터티이며 title/startsOn/endsOn/status/version을 가집니다. 기간은 Seoul 지역 날짜로 관리하며 시간 점유를 만들지 않습니다.
일정은 기존 UTC 구간·충돌 경계를 그대로 사용하고 선택적 projectId를 연결합니다. 할 일은 선택적 dueDate와 projectId를 가집니다. 연결은 인증된 소유자의 프로젝트만 허용합니다.
프로젝트 삭제는 연결된 일정·할 일이 있으면 거부합니다. 먼저 연결을 해제해야 합니다. 기존 데이터에는 날짜나 프로젝트를 임의로 부여하지 않습니다.
외부 데이터가 갱신되어도 사용자가 지정한 프로젝트·할 일 날짜를 보존합니다. 원격 변경의 제목·시간은 기존 동기화 정책으로 갱신합니다.

로그인/초기 설정이 성공하면 owner 화면 조립 직후 오늘 브리핑을 한 번 엽니다. 주기 재조회와 일반 새로고침은 자동으로 브리핑을 다시 열지 않습니다. ‘오늘 브리핑 보기’로 재조회 후 다시 열 수 있습니다.
브리핑 시간대는 Asia/Seoul. 일정은 당일 [00:00,다음날00:00)과 겹치는 항목을 시간순으로 보여줍니다. 전날부터 계속되는 일정과 종료 자정도 이 경계를 따릅니다.
할 일은 dueDate가 당일인 항목만 표시하고 날짜 미지정 개수를 별도로 알립니다. 프로젝트는 미완료 항목을 기한 순으로 표시하며 예정·진행·기한 지남을 구분합니다.
모달이 열린 동안 자동 화면 재렌더는 중지합니다. native dialog의 포커스 제한과 Escape 닫기를 사용하고 닫힌 뒤 브리핑 버튼으로 포커스를 복귀합니다.

이번 변경은 PC 웹/EXE 경로에 적용됩니다. Android 보조 앱은 기존 Google 캘린더 입력 역할을 유지하며 프로젝트 관리와 이 브리핑을 포함하지 않습니다.
