# ORBIT Android 보조 앱

**책임**: 비밀번호 잠금, 사용자가 허용한 카카오톡 알림을 기기 내부 검토함에 보관, 확인 후 지정 Google 캘린더에 일정 저장.
**연결 규칙**: Android Calendar Provider의 쓰기 가능한 `charlie.sungjin@gmail.com` 캘린더만 선택. Google의 Android 동기화 어댑터가 클라우드에 전송하고 PC는 읽기 전용 Google API로 가져옵니다.
**금지**: 전체 카카오톡 DB 접근, 동의 없는 알림 읽기, 확인 없는 일정 생성, Google 계정 비밀번호 수집.
**완료 판단**: APK 빌드/서명 확인과 기기에서 권한·알림·중복·확인·Google 동기화 검증을 구분합니다.

Android 8.0(API 26) 이상. PC 앱과 별개의 기기 로컬 비밀번호를 초기 설정합니다.
앱에서 알림 접근 및 캘린더 권한을 허용하고 Google 계정의 일정 동기화를 켜세요.
알림 수집 스위치는 기본 꺼짐입니다. 메시지 내용이 숨겨진 알림, 알림 미발생 대화, 앱 설치 전 대화는 가져오지 못합니다.
반드시 검토 후 저장합니다. 배터리 최적화·기기 제조사 정책 때문에 알림 수집이나 Google 동기화가 지연될 수 있습니다.

PC 웹 전체의 모바일 원격 접속판은 아닙니다. 독립 Android 앱에서 입력·알림 후보 확인·Google 일정 추가를 제공합니다.
공개 HTTPS 서버 없이 localhost PC 주소로 휴대폰이 접속할 수 없습니다.
빌드: `scripts/build-android.ps1`. SDK 바이너리와 개발 서명 키는 build 폴더에만 보관하고 배포하지 않습니다.
