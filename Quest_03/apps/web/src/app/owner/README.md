## 로컬 구현 상태 · 2026-10-29

index.mjs: 대시보드·기능 탭 조합과 세션 오류 안내.
dashboard.mjs: 화면 높이에 맞춘 달력·할 일·승인함 구성. 입력/연동 메뉴·검토함과 15초 간격 변경 감지도 조합합니다. 편집 중에는 자동 재렌더를 미룹니다.
daily.mjs/daily-model.mjs: 로그인 직후 오늘 시간별 일정·날짜 지정 할 일·프로젝트 브리핑. 일반 데이터 재조회 시 팝업이 반복해서 열리지 않습니다. 브리핑 버튼으로 다시 열 수 있습니다.
hero.mjs: 메인 소개 영역, 실제 요약 수치와 화면 이동 버튼, aria-hidden 입체 달력 장식. owner-theme.css가 개인 화면에만 색상과 깊이를 적용합니다.
상단의 예정 파일·완료 판단은 설계 사양입니다. 실제 검증은 evidence/local/verification.md에 기록했습니다.
