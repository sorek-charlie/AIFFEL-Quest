경로: `apps/web/src/features/calendar`

**책임**: 같은 일정 데이터를 2D·3D 뷰모델로 제공.

**연결 규칙**: 명시적 저장 결과로 화면 갱신. 서버 충돌 응답 표시.

**금지**: 화면 드래그만으로 서버 저장 성공 판정.

**구현 시 배치할 파일**: Calendar2D.tsx, EventEditor.tsx, calendarViewModel.ts. 이름은 예정안이며 README 외 소스의 존재를 의미하지 않습니다.

**완료 판단**: 이 모듈의 요구사항과 대응하는 `docs/quality/test-matrix.md`의 시나리오를 충족하고, 실제 실행 결과를 기록합니다.

현재 단계: 설계·폴더 구성. 기능 구현과 실행 검증은 아직 진행하지 않았습니다.

## 로컬 구현 상태 · 2026-10-29

index.mjs: 일정 생성·수정·취소와 공통 목록.
month-model.mjs: Seoul 날짜·월 이동·주 수·여러 날 일정의 표시 모델. 실제 월간 달력과 날짜 선택, 전체 일정 복귀를 제공합니다. 단위 테스트로 윤년·연도 이동·종료 자정의 반개구간을 검증합니다.
상단의 예정 파일·완료 판단은 설계 사양입니다. 실제 검증은 evidence/local/verification.md에 기록했습니다.

전체 일정 옆의 월 선택과 달력을 동기화하며 목록은 선택 월에 겹치는 일정만 표시합니다. 서울 시간 월말 자정 경계는 종료 시각을 제외합니다.


일정 만들기·안내 사이드바를 제거하고 데스크톱에서 월 달력과 월별 전체 목록을 나란히 표시합니다. 추가는 상단 입력, 수정은 공통 입력 대화상자를 사용합니다. 작은 화면은 세로 배치합니다.


## 로컬 달력 표시 · 2026-11-05
`korean-schedule.mjs`는 2026-12~2027-12 원본 13장의 참고 자료 298건과 음력 표기를 제공한다. `korean-schedule-view.mjs`는 날짜별 기념일·세무 건수, 월별 전체 참고 목록, 대시보드 세무 가로 영역을 렌더링한다. 개인 DB/충돌 판단과 분리된다. 원본 사진과 OCR 출력은 공개하지 않는다. GitHub 업데이트는 사용자 요청으로 중단했다.

세무 내용은 각 해당일에 전체 표시하며 날짜 칸은 내부 스크롤 없이 내용에 따라 높이가 늘어난다. 긴 달력은 페이지 스크롤을 사용한다(2026-11-05 로컬 수정).
