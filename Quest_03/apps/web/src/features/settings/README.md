**책임**: 시간대·공유 링크·2D/3D 보기·알림 환경설정.

**연결 규칙**: 설정 저장도 백엔드 검증을 거침.

**금지**: 외부 캘린더나 메일 자동 연결.

**구현 시 배치할 파일**: ProfileSettings.tsx, DisplaySettings.tsx. 이름은 예정안이며 README 외 소스의 존재를 의미하지 않습니다.

**완료 판단**: 이 모듈의 요구사항과 대응하는 `docs/quality/test-matrix.md`의 시나리오를 충족하고, 실제 실행 결과를 기록합니다.

현재 단계: 설계·폴더 구성. 기능 구현과 실행 검증은 아직 진행하지 않았습니다.
