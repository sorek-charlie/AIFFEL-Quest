# 웹 앱

라우트 진입은 src/app, 기능은 src/features, 3D 표현은 src/scene, API·세션·캐시는 src/platform에 둡니다.
공개·개인 화면은 별도 bundle boundary를 사용하고 3D는 개인 라우트 진입 후만 로드합니다.

현재 브라우저 ES modules 기반 로컬 화면이 있습니다. `src/app/main.mjs`에서 owner/public 모듈을 분리하여 로드합니다.
features에 Todo·일정·승인함·공개 신청·설정을 배치했습니다. 모든 저장은 platform/api를 거칩니다.
공간 보기는 같은 DOM에 CSS perspective를 적용하며 2D로 복귀할 수 있습니다. WebGL 3D는 미구현입니다.

React·TypeScript·Vite·R3F 방향은 후속 검토 범위입니다. 현재는 외부 npm 의존성이 없습니다.

대시보드와 로그인 팝업은 three-day-model/three-day의 동일한 날짜별 projection을 사용합니다. 일정은 서울 날짜와 겹치는 시간, 할 일은 dueDate, 프로젝트는 시작~종료 기간으로 분류합니다. 세 표를 세로 배치하고 각 표는 어제/오늘/내일 열을 표시합니다. 많은 내용은 키보드 접근 가능한 셀 내부에서 스크롤합니다. 월간 달력은 내 일정 메뉴에 유지합니다.

2026-10-30 오늘 상세: 로그인 팝업은 오늘만 표시하며, 메인은 어제/오늘/내일 폭 1:4:1입니다. demo-state는 표시 전용이고 실제 저장과 예약 점유에 참여하지 않습니다. 첫 화면 기본 예시 모드는 같은 탭의 sessionStorage에서 실제 보기 전환을 기억합니다. 일정 내용/참석자/장소, 프로젝트 수동 진척률/메모를 입력 구분 폼에서 저장합니다. 진척률을 비우면 전체 연결 할 일 완료 비율을 표시하며, 연결 할 일이 없으면 미설정으로 표시합니다.
