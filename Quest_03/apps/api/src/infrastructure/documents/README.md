# 문서·이미지 가져오기

책임: 허용한 파일에서 글자를 읽어 검토 후보로 변환합니다.
연결 규칙: 인증된 업로드 API만 호출하며 선택한 일정·할 일·프로젝트 종류를 유지합니다. Windows 내장 OCR·PDF와 DOCX XML을 사용합니다.
금지: 외부로 원본 전송, 첨부만으로 일정 자동 저장, 파일명으로 실행 경로 구성.
완료 판단: TXT 인증·검토 통합 테스트 및 합성 DOCX·PNG·PDF 실제 추출 확인. 임시 원본은 처리 후 삭제합니다.

Windows OCR 단어 좌표로 레슨코드·날짜·제목·주요내용 표를 복원한다. 명시된 연도만 사용한다. 프로젝트로 첨부한 날짜별 표는 부모 프로젝트와 일별 할일 후보를 생성하며 확정 전 저장하지 않는다. 원본 PDF·추출 레이아웃은 제출 소스에 포함하지 않는다.
