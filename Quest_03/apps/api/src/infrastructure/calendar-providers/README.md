# calendar-providers

책임: 직접 입력과 Google Gmail·일정 가져오기를 위한 개인 계획 관리.

연결 규칙: 인증된 API와 공개 export만 사용하고 저장은 서버에서 검증합니다.

금지: 고객 예약 접수·확정, 휴대폰·카카오톡 가져오기, 문자·카카오톡 송수신, 비밀값 공개.

완료 판단: 현재 PRD와 자동·UI 검증 결과를 기준으로 판단합니다. 기존 개인 데이터와 적용 migration은 유지합니다.

Google 자동조회는 Asia/Seoul 08/12/18/24시 고정 스케줄이다. 앱 시작 즉시 최신 도래 시각과 서비스별 coveredThrough를 비교하고 누락 조회를 한 번 보충한다. 실행 중에는15초마다 비교하므로 절전 복귀·네트워크 복구 후에도 누락을 검사한다. 네트워크 이벤트를 별도로 구독하지 않는다.

서비스별 lastSuccessAt/coveredThrough는 완전 성공에만 갱신한다. 부분 조회·권한 오류는 성공으로 처리하지 않는다. 같은 시간 구간에서 초기1회+30초/120초 후 재시도2회, 총3회로 제한한다. 시도·대기 상태는 암호화 설정에 보존한다. 다음 정시 구간에서는 다시 시도하며 권한 재연결은 connectionRevision 변경으로 재시도를 허용한다.

수동 요청은 진행 중이면 하나로 합쳐 대기한다. Gmail 후보 검토·캘린더 기존 충돌 경계를 유지한다. 최초 Gmail 최근7일, 장기 누락은 마지막 성공 이후를 포함해 최대366일까지 조회하며 한도를 넘으면 partial로 표시한다. 캘린더는 변경 커서를 사용하고410만료 시 전체 조회를 한 번 다시 시도한다.

PC 로컬 점검: `node scripts/google-sync.mjs --status` 또는 `--recover --wait-seconds 120`. CLI는 별도 Google 조회나 인증 우회를 하지 않는다. 기존 암호화 DB를 읽기 전용으로 열어 허용된 상태 필드만 출력하고, 앱이 꺼져 있으면 로컬 실행파일을 시작하여 앱의 자동 보충 결과를 기다린다. 자료·키·토큰은 출력하지 않는다.
