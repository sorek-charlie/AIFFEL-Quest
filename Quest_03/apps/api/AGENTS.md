# API 작업 추가 지침

루트 AGENTS.md를 함께 적용합니다.

- body/query의 owner_id 대신 인증된 actor를 사용합니다.
- 공개 응답은 DTO 허용 목록으로 만듭니다. DB row 전체를 반환하지 않습니다.
- 일반 사용자 작업에 service-role 우회를 적용하지 않습니다.
- 승인·일정 이동·공개 규칙 수정의 잠금 경계를 일치시킵니다.
- 요청·쿠키·JWT·연락처 전체를 로그에 넣지 않습니다.
- 로컬 개발 인증은 production 또는 외부 bind에서 실패하도록 합니다.
- 외부 알림은 커밋 뒤 처리하며 미연결 상태에서 발송 성공을 보고하지 않습니다.
