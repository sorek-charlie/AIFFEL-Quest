# PRD · 이성진 개인 일정 관리

과제 D-4 | 개정 2026-11-03 | 마감 2026-11-05 23:59 (한국 시간)

## 1. 목표와 범위
개인 사용자가 직접 입력·문서/이미지 첨부 또는 Google에서 가져온 일정·할 일·프로젝트를 관리한다. 휴대폰·카카오톡·ICS 가져오기, 고객 예약 접수·승인, 문자·카카오톡 송수신은 제외한다.

## 2. 기능과 수용 조건
- 메뉴: 왼쪽 대시보드·일정·할 일·프로젝트·설정, 오른쪽 입력·구글연동·검색. 글꼴과 크기는 유지한다.
- 입력 메뉴: 일정·할 일·프로젝트 각각 직접 입력·문서파일 첨부·이미지 첨부를 제공한다. 첨부 내용은 선택한 종류로 검토 후 저장한다.
- 직접 입력: 일정·할 일·프로젝트 추가·조회·수정·삭제, 할 일 완료, 프로젝트 연결·진척률. 일정 시간은 10분 단위이며 기존 시간은 보존한다.
- Google 일정: 지정 계정 연결, 기간 선택·미리보기·선택 저장, 중복 제외·충돌 검토. Google 일정 원본은 수정하지 않는다.
- Gmail: 기간별 조회, 일정·스케줄(할 일)·프로젝트·기타·스팸 후보 추천. 가까운 미래 날짜부터 표시하고 원문 링크·분류 근거를 제공한다. 사용자 확인 후 저장한다. 스팸 이동은 별도 수정 권한·개별 확인이 필요하다.
- 과제 Todo: 길 A(SQLite) 완료 후 길 B(Supabase) 선택. 각 저장소에서 CRUD·완료·삭제·앱 재시작 후 보존을 확인한다. 두 저장소는 독립적이다.

## 3. 데이터와 구조
브라우저 → 인증된 Node API → SQLite 또는 Todo용 Supabase REST. 일정·할 일·프로젝트는 소유자와 버전을 가지며 오래된 수정·삭제를 거부한다. 일정 충돌 검사와 저장은 같은 트랜잭션에서 처리한다.

## 4. 보안과 품질
Google 지정 계정은 charlie.sungjin@gmail.com이다. OAuth 설정·토큰은 Git 제외 로컬 DB에 암호화 저장한다. Supabase CRUD는 사용자 JWT와 RLS를 사용하며 관리자 키를 거부한다. 모바일 360px·키보드·2D 화면을 확인한다.
