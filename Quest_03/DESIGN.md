# 디자인 방향 · 한 제품, 두 사용 환경

## 개인 화면

현재 적용: 사용자의 후속 요청으로 어두운 배경을 제거하고 밝은 크림 바탕과 Luminous Blue 해석 색상, 라임·살구 카드를 사용합니다. WGSN/Coloro의 2027 색상 전망을 참고한 UI 해석이며 ‘2027년 실제 최다 유행’이라는 확정 주장이 아닙니다. 큰 장식 배너는 작은 요약 스트립으로 바꾸고 1366×768/1280×720에서 달력·할 일·승인함 섹션이 화면에 들어오게 구성했습니다. 항목이 많으면 각 섹션 내부에서 스크롤합니다. 모바일은 세로 스크롤을 사용합니다.
참고: [WGSN 2027 Luminous Blue](https://www.wgsn.com/en/blog/colour-year-2027-luminous-blue).

2026-10-29 로컬 화면 개정: 사용자 요청에 따라 보라·민트·코랄 그라데이션, 깊이 있는 카드 그림자, CSS 입체 달력과 떠 있는 패널을 적용했습니다. 장식은 aria-hidden이며 실제 일정과 혼동하지 않도록 실제 날짜와 연동되지 않는 상징 달력으로 사용합니다. 모바일에서는 세로 구성으로 바뀌며 reduced-motion과 2D 복귀를 지원합니다.

어두운 남색 공간에 시간 그리드와 일정 블록을 배치합니다. 장식용 회전 우주보다 시간·분류를 읽을 수 있는 3D 주간 보기를 우선합니다.
좌측 탐색 / 중앙 2D·3D 일정 / 우측 선택 일정·승인함 구조를 사용합니다. 일정을 수정하는 입력은 읽기 쉬운 DOM 패널에 둡니다.

## 고객 화면

밝은 배경, 남색 글자, 파란 행동 버튼, 큰 날짜·시간 버튼으로 구성합니다. 한 화면에서 한 결정을 유도합니다.
주최자·미팅 길이·시간대 → 날짜 → 시간 → 이름/연락처 → ‘승인 대기’ 확인 순서입니다.
마지막 버튼은 ‘예약 확정’이 아니라 ‘예약 요청 보내기’입니다.

## 공통 원칙

- 색만으로 pending/confirmed/rejected를 구분하지 않고 텍스트와 아이콘을 함께 사용합니다.
- 본문 16px 기준, 모바일 버튼 터치 영역 44px 이상을 목표로 합니다.
- 카드 24px, 입력·버튼 8px 모서리를 출발점으로 사용하고 간격은 8px 기반입니다.
- 기본 폰트는 시스템 한국어 sans-serif. 추후 Noto Sans KR·Inter 등의 라이선스를 확인하여 추가합니다.
- 모션은 의미 있는 선택 전환에만 쓰고 prefers-reduced-motion을 존중합니다.
- 실제 대비·키보드·모바일 검증 후 완료 판정합니다.

색상 의미값은 `packages/design-tokens/src/tokens.json`이 기준입니다.
밝은 화면은 Refero Styles의 Calendly 분석에서 여백·남색/파랑 대비를 참고해 프로젝트용으로 재구성했습니다. 브랜드 로고·스크린샷·상용 폰트는 가져오지 않았습니다.
제공된 디자인 영상은 전체 내용을 직접 검증하지 못했으므로 영상의 특정 화면을 그대로 복제했다고 주장하지 않습니다.
