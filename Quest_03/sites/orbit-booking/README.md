# orbit-booking

책임: 직접 입력과 Google Gmail·일정 가져오기를 위한 개인 계획 관리.

연결 규칙: 인증된 API와 공개 export만 사용하고 저장은 서버에서 검증합니다.

금지: 고객 예약 접수·확정, 휴대폰·카카오톡 가져오기, 문자·카카오톡 송수신, 비밀값 공개.

완료 판단: 현재 PRD와 자동·UI 검증 결과를 기준으로 판단합니다. 기존 개인 데이터와 적용 migration은 유지합니다.

공개 진입점 / 및 /viewer.html은 PC 실제 자료의 실시간 읽기 전용 화면이다. /api/v1/viewer는 비밀번호 없이 GET 열람만 허용한다. 데이터 변경 메서드는403, 인증되지 않은 owner API접근은401. 개인 DB 파일·메일 원문·자격증명은 공개하지 않는다. /owner.html의 개인 관리 인증은 기존 경계를 유지한다.

실시간 공개: PC의 public-viewer-live 명시적 활성화 시에만 events/tasks/projects 허용필드 전체를 전송한다. 서버는 다시 DTO를 투영한다. PC가 끊기면 마지막 반영 자료 전체를 계속 제공하고, PC에서 공개를 해제하면 자료를 삭제한다. 공개화면은5초폴링하며계정/원문메일/키/토큰을제공하지않는다. 예시/제출일스냅샷 제공은 제거했다.

외부 화면은 로컬의 CSS와 dashboardView/calendarView/tasksView/projectsView를 공유한다. 소유자 이벤트 핸들러를 바인딩하지 않으며 입력 폼·수정/삭제 버튼을 제거하고 완료 체크를 비활성화한다. 서버는 별도로 모든 자료 변경 메서드를 차단한다.

현재 평가자 모드: 열람 비밀번호 입력을 비활성화했다. 공개 GET state는 인증 없이 허용필드만 반환하고 POST/PUT/PATCH/DELETE는 모두403이다. PC 연결이 끊겨도 마지막 공개 자료 전체를 보관·제공한다. 공개 해제는 기존과 같이 자료를 삭제한다. 개인 owner 인증은 유지한다.

공개 열람에서도 입력·구글연동·검색 버튼과 메뉴를 열 수 있습니다. 일정·할 일·프로젝트 직접입력, 문서/이미지 첨부, Gmail·캘린더 화면은 미리보기만 제공하고 데이터 입력·첨부·저장·연결 변경은 비활성화합니다. 검색과 날짜 이동은 사용 가능합니다.
