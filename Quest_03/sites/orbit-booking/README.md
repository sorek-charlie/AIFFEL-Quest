# orbit-booking

책임: 직접 입력과 Google Gmail·일정 가져오기를 위한 개인 계획 관리.

연결 규칙: 인증된 API와 공개 export만 사용하고 저장은 서버에서 검증합니다.

금지: 고객 예약 접수·확정, 휴대폰·카카오톡 가져오기, 문자·카카오톡 송수신, 비밀값 공개.

완료 판단: 현재 PRD와 자동·UI 검증 결과를 기준으로 판단합니다. 기존 개인 데이터와 적용 migration은 유지합니다.

공개 진입점 / 및 /viewer.html은 PC 실제 자료의 실시간 읽기 전용 화면이다. /api/v1/viewer는 별도 서명 쿠키로 인증하며 데이터 변경 메서드는403, 공개 세션으로 owner API접근은401. 개인 DB 파일·메일 원문·자격증명은 공개하지 않는다. /owner.html의 개인 관리 인증은 기존 경계를 유지한다.

실시간 공개: PC의 public-viewer-live 명시적 활성화 시에만 events/tasks/projects 허용필드 전체를 전송한다. 서버는 다시 DTO를 투영하고 현재 PC lease/heartbeat를 검사한다. PC가20초이상연결되지않거나공개를해제하면503. 공개화면은5초폴링하며계정/원문메일/키/토큰을제공하지않는다. 예시/제출일스냅샷 제공은 제거했다.

외부 화면은 로컬의 CSS와 dashboardView/calendarView/tasksView/projectsView를 공유한다. 소유자 이벤트 핸들러를 바인딩하지 않으며 입력 폼·수정/삭제 버튼을 제거하고 완료 체크를 비활성화한다. 서버는 별도로 모든 자료 변경 메서드를 차단한다.
