# settings

책임: 직접 입력과 Google Gmail·일정 가져오기를 위한 개인 계획 관리.

연결 규칙: 인증된 API와 공개 export만 사용하고 저장은 서버에서 검증합니다.

금지: 고객 예약 접수·확정, 휴대폰·카카오톡 가져오기, 문자·카카오톡 송수신, 비밀값 공개.

완료 판단: 현재 PRD와 자동·UI 검증 결과를 기준으로 판단합니다. 기존 개인 데이터와 적용 migration은 유지합니다.

검토함은 페이지당 20개만 렌더링합니다. 시간 선택은 숨겨진 입력란에 생성하지 않고 일정으로 전환한 카드에서 생성합니다. 1,360개 합성 후보의 페이지 이동·키보드 동작을 확인했습니다.


2026-11-03: 메뉴·버튼·설명 문구를 짧게 정리했습니다. CSS·폰트 파일은 변경하지 않았습니다. 연결·보안·저장·삭제 안내는 유지합니다.


프로젝트 저장 후 실제 프로젝트 목록으로 이동합니다. 대시보드는 실제 데이터를 기본 표시하며 예시 보기는 명시적으로 선택합니다. 연결 실패 시 입력창을 유지하고 재접속 안내를 표시합니다.


상단은 입력·구글연동·검색, 왼쪽은 대시보드·일정·할 일·프로젝트·설정입니다. 첨부는 검토 후 저장하며 Google 화면에서도 대시보드로 돌아갈 수 있습니다.


첨부 완료 즉시 해당 파일의 후보만 전용 검토 대화상자로 표시합니다. 제목·종류·날짜 수정과 항목 선택·저장·제외·나중에 검토를 지원하며 확인 전에는 계획에 저장하지 않습니다. 같은 첨부의 미처리 후보 ID를 반환해 재검토할 수 있습니다.


검토창은 화면 너비96%·높이94%이며 문서/이미지 후보 모두 구분·제목·날짜/시간·장소·참석자·주요내용·확정 버튼을 제공한다. 수정한 세부 내용은 인증된 확정 API에서 길이를 검증하고 저장한다.

직접 입력 날짜는 공통 큰 달력으로 선택한다. 입력창1040px/달력640px, 모바일96vw. 날짜선택은 원본form값과10분단위시각을 유지한다.


문서·이미지검토는 구분/제목/날짜/시간/장소/참석자/주요내용/확정 표다. 첨부는100행까지한번에, 검토함은20행기본. 프로젝트부모행선확정후날짜별할일자동연결. 원문값이없는시간/장소/참석자는만들지않는다.

입력 메뉴는 일정·할 일·프로젝트·문서함 각1개. 종류별 직접입력/문서첨부/이미지첨부. 종류는 하나만 펼치며 문서함은 하위 메뉴 없이 표 검토로 이동한다.
